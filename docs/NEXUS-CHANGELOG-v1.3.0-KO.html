Body Change NG v1.3.0

오버레이·의상 보정·미리보기 복원

  • 여러 저장 오버레이를 각각 다른 슬롯으로 복원합니다. 기존 슬롯과 색상을 유지하고 여유 공간이 있으면 중복 저장 슬롯도 분리하며 다른 모드가 점유한 슬롯은 보존합니다.
  • 기본 바디 자동 검증 시 유효한 가슴·유두 의상 보정을 유지합니다. 실제 바디 복구 후에는 의상 보정을 다시 판단하며 명시적 초기화·삭제 준비 동작은 유지합니다.
  • 플레이어 스킨 미리보기 취소 복원은 RaceMenu를 닫은 뒤 처리합니다. NPC 언로드 시 복원은 유지하며 새 선택·세션 전환 시 오래된 작업은 무효화합니다.
  • RaceMenu에서 플레이어를 편집하는 동안 바디 미리보기 취소·남은 미리보기 키 정리를 보류하고 닫힌 뒤 복원합니다. 언로드 시 정리와 새 활성 미리보기 보호는 유지합니다.
  • RaceMenu 진입으로 오버레이 미리보기 취소가 사라지지 않도록 수정했습니다. 부위별 최신 선택과 액터 실행 순서·지연 쓰기를 유지하여 오래된 취소가 새 미리보기·색상 편집·확정·초기화를 덮어쓰지 않게 했습니다.
  • 로드 또는 RaceMenu 종료 시 플레이어의 저장된 기본 바디를 복원한 뒤 의상 보정도 재평가합니다. 비활성화·누드·SFS·지정/자동 보정의 기존 정책을 따르며 명시적 초기화·모드 삭제 준비는 보정을 다시 적용하지 않습니다.

수정 범위와 검사

기존 기능·배포 규칙·저장 형식·의존성·SE/AE 지원 범위는 유지합니다. 새 영구 캐시나 전체 액터 상시 스캔은 추가하지 않았습니다.

Release 빌드, 오프라인 회귀 실행 파일 34개, 보조 검사 19개 통과. 호스트 할당 검사에서 잔여 증가가 없었으며 보류 중 복원은 매 프레임 새로 할당하지 않습니다. 새 인게임 테스트는 수행하지 않았습니다.
