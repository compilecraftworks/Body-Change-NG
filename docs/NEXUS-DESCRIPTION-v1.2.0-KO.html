Body Change NG v1.2.0

플레이어와 NPC의 BodySlide 프리셋과 바디스킨, 플레이어의 틴트마스크를 게임 안에서 실시간으로 변경하고, 조건을 편집해 BodySlide 프리셋과 바디스킨을 NPC들에게 배포합니다.

네이티브 인게임 GUI · 게임패드 지원 · 규칙 기반 NPC 배포

지원 바디: CBBE 3BA · BHUNP/UNP · UBE 2.0 · HIMBO · SAM · 바닐라 여성/남성

소개

Body Change NG는 하나의 인게임 인터페이스에서 BodySlide 바디모프 프리셋, 액터 스킨 텍스처, 선택형 성기 애드온 스킨, 플레이어 RaceMenu 틴트 레이어를 변경하는 네이티브 SKSE 플러그인입니다. 바디와 스킨을 NPC에게 자동 배포하는 우선순위 규칙 편집기, 세이브별 결과 복구, 즐겨찾기, 의상 보정, 선택적 OBody NG JSON 가져오기도 포함합니다.

바디 형태는 계속 RaceMenu BodyMorph 데이터입니다. 1.2.0은 과거의 범용 스킨 재도색 경로를 액터의 네이티브 TextureSet → ArmorAddon → Skin Armor 그래프로 교체했습니다. 선택 스킨이 NPC base의 정상 스킨 원본이 되므로, 장갑·신발·의상 착탈 여부를 BCNG가 추적하지 않아도 Skyrim 자체 시스템이 알몸 몸·손·발·얼굴을 같은 스킨에서 다시 생성합니다.

1.2.0 핵심 변경점

  • 네이티브 Skin Armor/TXST 백엔드 — 액터가 현재 쓰는 공급자 그래프를 깊게 복제하고 원본 텍스처 채널을 모두 보존한 뒤, 선택팩에 실제로 있는 DDS 부위·채널만 덮어써 NPC ActorBase에 연결합니다.
  • 장비와 독립된 기본 스킨 — 일반 바디스킨은 의상 변경 때 다시 칠하지 않습니다. 의상이 실제 바디를 노출하면 Skyrim이 이미 선택된 Skin Armor에서 해당 부위를 생성합니다.
  • 부위별 정확한 라우팅 — 몸·손·발·얼굴, 3BA 질/항문, BHUNP 질/항문/내부, 수인종 꼬리, 외부 성기 애드온 역할을 분리합니다. 없거나 애매한 역할을 다른 부위로 보내지 않습니다.
  • 일반 바디 계열/UBE 카탈로그 — Legacy는 CBBE/3BA·BHUNP/UNP·바닐라 여성/남성·HIMBO·SAM처럼 Skyrim의 일반 actors\character 텍스처 구조를 쓰는 스킨팩을 뜻합니다. !UBE\Body 또는 !UBE\Head 경로가 명시된 팩만 UBE로 분류합니다. 세부 재질 경로는 팩 이름이 아니라 적용할 액터의 런타임 바디 계열에서 결정합니다.
  • 안전한 부분팩 — 모든 부위와 재질 채널은 선택 사항입니다. 없는 DDS는 현재 공급자 값을 유지하고 몸·손·발·얼굴·성기 파일을 서로 빌려 쓰지 않습니다.
  • UBE 2.0 실제 그래프 지원 — 확인된 슬롯 53 몸과 별도 손·발 ArmorAddon은 UBE Body 아틀라스를, 얼굴은 Head 아틀라스를 사용합니다. 전용 TXST 생성은 확인된 정식 UBE 알몸 모델 복제본에만 제한됩니다.
  • RSV 소유권 호환 — 현재 Racial Skin Variance 그래프를 공급자로 사용할 수 있습니다. RSV 폼이 바뀌면 그 현재 값을 다시 원본으로 삼고 BCNG가 여전히 소유한 포인터만 복원합니다. 얼굴 브리지는 RSV 저장 키를 만들거나 삭제하지 않습니다.
  • 외형 기능 완전 분리 — 바디모프, 네이티브 기본 스킨, 플레이어 틴트, 남성 SOS/TNG, 여성 후타나리, RSV 얼굴, 의상 보정이 별도 상태와 작업 채널을 사용합니다. 한 기능을 고치거나 초기화해도 다른 기능을 지우지 않습니다.
  • NPC 배포 저장 안정화 — BodyMorph는 액터 레퍼런스 단위, 네이티브 스킨은 ActorBase 단위입니다. 실제 작업 성공 뒤에만 완료로 저장하며, 규칙이 바디 또는 스킨을 변경하지 않으면 그 범주의 기존 저장 결과를 유지합니다.
  • 배포 규칙 편집·저장 개선 — 샘플도 수정·순서 변경·삭제할 수 있고 새 ID 충돌을 막습니다. 앞선 광역 규칙이 뒤 규칙을 가리면 세 언어로 경고하며, 기본 이름은 한국어·영어·중국어 UI를 따릅니다. JSON은 검증된 임시 파일과 원자 교체로 저장합니다.
  • 명시적인 버전 경계 — Skyrim SE 1.5.97과 검증된 AE 1.6.x(1.6.1179까지)를 지원합니다. RaceMenu 인터페이스 세대를 분리해 처리하고 미확인 레이아웃은 실패 폐쇄합니다. Skyrim VR 빌드는 제공하지 않습니다.

Body Change NG를 사용하는 이유

OBody NG와 비교

두 모드 모두 빌드된 바디를 RaceMenu BodyMorph와 TRI 데이터로 변형합니다. 차이는 그 위에서 선택·배포·상태를 관리하는 방식입니다.

  • 하나의 네이티브 인터페이스 — F7 창에서 플레이어와 로드된 NPC, 바디프리셋, 스킨, 플레이어 틴트, 즐겨찾기, 배포 규칙을 관리합니다.
  • 액터별 호환 목록 — 프리셋은 액터의 런타임 BodyFamily에 맞추고, 스킨 구조·종족·성별은 별도로 검사합니다.
  • 명시적인 바디·스킨 풀 — 각 규칙에서 정확한 후보를 고르고 바디와 스킨을 각각 후보 배포·기본값·제외·변경 없음으로 설정합니다.
  • 보이는 위→아래 우선순위 — 처음 일치한 규칙이 두 범주의 결정을 소유하며 광역·세부 조건의 순서를 게임 안에서 바꿉니다.
  • 즉시 또는 다음 실행 배포 — 로드된 NPC에게 지금 적용하거나 현재 세션 활성 규칙을 바꾸지 않고 다음 실행용 초안을 저장합니다.
  • 세이브별 결과 — 직접 선택과 평가된 NPC 결과는 SKSE 코세이브에 저장하며 변경 없는 액터의 전체 재배포를 피합니다.
  • 분리된 실시간 상태 — 미리보기·확정 바디모프·의상 보정·네이티브 바디스킨·틴트·성기 애드온 스킨의 소유권을 분리합니다.
  • 선택적 이전 경로 — 기존 OBody NG JSON의 지원되는 NPC 배포와 OBody NG ORefit 데이터를 사용자가 명시적으로 가져올 수 있습니다.

기존 메시 슬롯 방식과 비교

기존 슬롯 방식은 미리 정한 슬롯마다 별도 바디 메시와 ESP의 Skin Armor·HeadPart·TextureSet 레코드를 준비해야 합니다. Body Change NG는 고정 CustomSet 슬롯을 사용하지 않습니다.

  • 바디 형태는 설치된 BodySlide XML에서 선택하고 BodyMorph로 적용합니다.
  • 1.2.0은 액터의 현재 네이티브 TXST → ArmorAddon → Skin Armor 공급자 그래프를 깊게 복제하고 전용 복제본의 확인된 채널만 바꿉니다.
  • 바디 형태와 스킨을 하나의 준비된 메시·레코드 세트로 묶지 않고 독립적으로 선택합니다.
  • 네이티브 기본 스킨을 NPC ActorBase에 연결하므로 의상 상태를 BCNG가 추적하지 않아도 Skyrim이 노출된 몸·손·발·얼굴을 다시 생성합니다.
  • 플레이어·NPC 직접 선택, 조건 배포, 즐겨찾기, 실행 중 새로고침, 플레이어 틴트를 한 인터페이스에서 제공합니다.

주요 기능

바디프리셋

  • 플레이어 또는 로드된 NPC의 호환 BodySlide 프리셋을 즉시 미리보기·확정합니다.
  • 액터 체중에 따라 low/high 값을 보간합니다.
  • 미리보기·확정·의상 보정은 서로 다른 BCNG 소유 BodyMorph 키를 사용합니다.
  • 반복 적용해도 같은 절대 결과에 도달하며 다른 모드의 모프 키를 전체 삭제하지 않습니다.
  • 액터의 런타임 BodyFamily를 보수적으로 판정해 메인 목록을 필터링하며, 불확실하거나 여러 계열에 해당하는 프리셋은 안전한 표시 폴백을 유지합니다.
  • NPC 규칙 풀은 모드 설정의 여성·남성 바디 타입을 사용하고 실제 배포 직전에도 호환성을 다시 확인합니다.
  • BodySlide XML 분류와 액터의 런타임 BodyFamily 판정은 스킨팩 분류와 독립적입니다.

바디스킨

  • 플레이어와 로드된 NPC에게 서로 다른 스킨팩을 적용합니다.
  • 수동 스킨·기본 스킨 선택은 접수 즉시 소유권을 잡아 액터 초기화나 자동 배포가 미리보기를 덮지 않게 합니다.
  • 몸·손·발·far skin과 선택적 얼굴 TXST를 현재 공급자에서 복제하므로 선택팩과 무관한 채널은 그대로 유지됩니다.
  • CBBE/3BA·BHUNP/UNP·바닐라·HIMBO·SAM용 일반 텍스처 트리는 Legacy로 묶고, 명시적 !UBE 아틀라스 구조만 UBE로 자동 분류합니다.
  • CBBE 3BA와 BHUNP/UNP의 질·항문 아틀라스는 정확히 일치하는 내부 지오메트리에만 연결됩니다.
  • HIMBO·SAM 스킨과 SOS/TNG 슬롯 52 텍스처를 한 팩에 둘 수 있습니다. 바닐라 남성 스킨도 지원하며, 현재 애드온 경로로 Regular·Muscular·Smurf 및 종족·노인 변형을 고릅니다.
  • 아르고니안·카짓은 종족·성별로 필터링하며 몸 아틀라스를 해당 종족의 네이티브 꼬리 역할에도 연결합니다.
  • Diffuse·Normal·Subsurface·Specular·호환 Detail과 노인·뱀파이어·종족 변형은 일치하는 파일이 있을 때만 적용합니다.
  • 네이티브 재구성 경계 뒤 최종 결과를 검증하고, 누락된 캐시 파일은 NPC 이벤트마다 전체 검색하지 않고 원본 팩에서 복구합니다.
  • 기본 스킨은 바디모프·틴트·후타나리·외부 모드 키를 건드리지 않고 캡처한 공급자 그래프로 복원합니다.

후타나리 스킨

  • 지원하는 여성 애드온이 실제 감지될 때만 탭이 표시됩니다: UBE SOS/TNG, UBE/CBBE TRX, CBBE 3BA ERF.
  • 성기 스킨 선택은 전체 바디스킨과 독립적입니다.
  • 애드온을 제거해도 선택을 저장하고, 지원 유형을 다시 장착하면 맞는 스킨을 복구합니다.
  • 없는 채널은 애드온의 원본 재질을 유지합니다.

플레이어 틴트마스크

  • 여러 RaceMenu 틴트팩을 설치하고 레이어별 DDS를 선택합니다.
  • 색상과 강도를 즉시 변경하고 BCNG 변경 직전의 정확한 원본 값으로 복원할 수 있습니다.
  • RaceMenu가 플레이어를 다시 만든 뒤 확정된 틴트 레이어를 복구합니다.
  • 플레이어 전용 기능입니다. 오버레이 기반 화장은 틴트마스크가 아니므로 이 탭에서 지원하지 않습니다.

NPC 조건 배포

  • 규칙을 위에서 아래로 평가하며 처음 일치한 규칙이 바디와 스킨 결정을 소유합니다.
  • 바디·스킨 각각 후보 배포, 명시적 기본값, 배포 제외, 변경 없음 상태를 구분합니다.
  • 성별, 커스텀 팔로워, 노인, 플러그인, 종족, 팩션, 키워드, 클래스, 이름, NPC Base FormID 조건을 지원합니다.
  • 팩션·종족·키워드·클래스는 플러그인과 로컬 FormID를 함께 보존해 이름 없는 레코드도 선택하고 로드 순서 변경에도 다시 해석합니다.
  • 후보 하나는 고정, 여러 개는 NPC별 안정적인 결과를 선택합니다.
  • 이미 죽었어도 3D가 로드된 NPC는 같은 규칙을 적용하며 플레이어·비활성·미로드·비 NPC 레퍼런스는 제외합니다.
  • 편집 가능한 기본 제외 8개는 커스텀 팔로워·노인·아르고니안·카짓을 다루며 샘플도 사용자 규칙과 동일하게 수정·삭제할 수 있습니다.
  • 전체 선택·전체 해제로 호환 바디 또는 스킨 풀을 빠르게 구성합니다.
  • 로드된 NPC에게 즉시 배포하거나, 현재 세션의 활성 규칙은 건드리지 않고 다음 실행용 초안만 저장할 수 있습니다.
  • 샘플과 사용자 규칙은 같은 수정·순서 변경·삭제 동작을 사용합니다.

규칙 파일: Data\SKSE\Plugins\BodyChangeNGdistribution.json

인게임 편집기가 이 파일을 씁니다. 모드나 MO2 프로필을 교체할 때 백업한 뒤 같은 경로로 복원하고 저장 값 불러오기를 누릅니다.

의상 보정·랜덤화

  • 지원되는 CBBE 3BA·BHUNP/UNP 액터의 의상 착용 시 가슴 보정과 별도 유두 보정 옵션을 제공합니다.
  • 지원되는 CBBE 3BA·BHUNP/UNP NPC의 유두·생식기 형태를 세이브에서 안정적으로 무작위화할 수 있습니다.
  • 슬라이더 구조가 다른 UBE 액터는 건너뛰며 UBE 플레이어·일반 계열 NPC 혼합 설치도 액터별로 판정합니다.
  • ORefit은 OBody NG의 기능명이며 BCNG 자체 기능명은 의상 보정입니다. OBody NG ORefit 규칙을 등록한 경우, BCNG 의상 보정은 가져온 의상별 지정 프리셋을 먼저 사용하고 현재 바디 이름의 정확한 -Refit, Female-Refit/Male-Refit, 절차적 보정 순서로 다음 후보를 찾습니다.

UI·입력

  • 한국어·영어·중국어 UI
  • Ctrl·Shift·Ctrl+Shift 조합을 포함한 F7 단축키 변경
  • 마우스, 방향키/WASD, 게임패드 D-pad 탐색과 선택·취소
  • 네이티브 IME, 유니코드 검색·이름, 즐겨찾기와 탭별 즐겨찾기 모아보기

필수 모드

  • Skyrim SE 1.5.97 또는 지원하는 Skyrim AE 1.6.x 런타임(1.6.1179까지)
  • 게임 버전에 맞는 SKSE64
  • 게임 버전에 맞는 Address Library for SKSE Plugins
  • 게임 버전에 맞고 BodyMorph 및 NiOverride/Override를 제공하는 RaceMenu
  • Build Morphs로 생성한 BodySlide 프리셋·호환 TRI 파일

Skyrim VR은 지원하지 않습니다.

설치·업데이트

  1. Release ZIP을 MO2로 설치하고 폴더 구조를 유지합니다.
  2. 개인 에셋이나 SKSE\Plugins\BodyChangeNGdistribution.json을 메인 모드 안에 보관했다면 업데이트 전에 백업합니다.
  3. 모드를 활성화하고 SKSE로 실행한 뒤 F7을 누릅니다.

1.2.0은 1.1.4와 분리된 새 아키텍처입니다. 두 버전 DLL을 섞지 마세요. 설정·배포 규칙·즐겨찾기·코세이브 식별자는 기존 위치에서 마이그레이션하지만, 1.2.0으로 장시간 진행하지 않은 세이브에서는 이전 DLL 백업이 가장 안전한 롤백 지점입니다.

사용법

  1. F7을 누르고 플레이어를 선택하거나 액터 새로고침 뒤 현재 로드된 NPC를 선택합니다.
  2. 바디프리셋 또는 바디스킨을 엽니다. 한 번 클릭은 미리보기, 더블클릭은 창을 유지한 확정이며 선택창을 닫으면 마지막 미리보기가 확정됩니다. 기본 항목은 해당 범주의 BCNG 선택을 해제합니다.
  3. 틴트마스크에서 플레이어의 기존 RaceMenu 레이어를 선택하고 색상·강도를 조절하거나 BCNG가 처음 변경하기 직전 값으로 복원합니다.
  4. 지원하는 여성 성기 지오메트리가 감지되면 독립된 후타나리 탭에서 SOS/TNG·TRX·ERF 유형에 맞는 스킨을 고릅니다.
  5. 모드 설정에서 여성·남성 NPC 바디 타입을 고르고 NPC 배포에서 조건과 풀을 편집한 뒤 지금 로드된 NPC에게 적용하거나 다음 실행용으로 저장합니다.
  6. 의상·랜덤화에서 지원되는 의상 보정·NPC 형태 무작위화 또는 OBody NG ORefit 규칙 등록을 선택합니다.
  7. 게임 실행 중 에셋을 추가·교체했다면 해당 목록의 새로고침을 누릅니다.

저장 범위: 액터 직접 선택과 평가 결과는 현재 SKSE 코세이브에 속하며 배포 규칙은 위의 별도 JSON에 저장됩니다.

선택적 OBody NG JSON 가져오기

Body Change NG는 OBody NG 또는 그 JSON 없이도 작동합니다. 기존 규칙을 재사용하려는 경우에만 다음 파일을 선택적으로 사용합니다.

Data\SKSE\Plugins\OBody_presetDistributionConfig.json

BodyChangeNGdistribution.json과 같은 폴더에 두되 두 파일을 합치거나 이름을 바꾸지 않습니다. BCNG는 명시적인 UI 동작에서만 OBody 파일을 읽고 원본은 수정하지 않습니다.

같은 OBody 파일명을 제공하는 MO2 모드가 여러 개면 MO2가 내용을 자동 병합하지 않습니다. BCNG는 가상 Data 경로에서 최종 승리한 파일 하나를 읽습니다. 배포 설정과 OBody NG ORefit 마스터 목록을 함께 써야 한다면 OBody 규칙끼리 미리 합쳐진 OBody 형식 파일을 사용하고, BCNG의 별도 BodyChangeNGdistribution.json과는 합치지 마세요.

  • NPC 배포의 저장 값 불러오기를 누르면 BCNG 저장 규칙과 함께 지원되는 OBody NPC 배포 데이터를 가져옵니다.
  • 프리셋 배포 제외 목록, NPC 이름/FormID 제외·지정, 플러그인·종족 제외, 팩션·플러그인·종족 지정, 여성·남성 기본 풀을 지원합니다. 프리셋 이름은 설치된 카탈로그와 일치해야 하며 누락된 이름은 건너뛰고 로그에 남깁니다.
  • 다시 가져오면 이전 OBody 가져오기 행만 교체하고 BCNG 샘플·사용자 규칙은 보존합니다. 가져온 행도 저장·배포 전에 화면에서 확인하고 편집할 수 있습니다.
  • 가져온 행도 모든 BCNG 규칙과 같은 위→아래 우선순위를 사용합니다. 앞쪽의 같은 성별 모든 NPC 규칙이 뒤의 구체적인 가져오기 행을 가릴 수 있으며, 이때 편집기가 경고하므로 구체적인 행을 위로 옮기거나 앞 규칙의 범위를 좁히세요.
  • 의상·랜덤화의 OBody NG 의상 보정 규칙 등록은 의상 이름·플러그인·FormID 제외, 이름·FormID 강제 보정, 여성·남성 의상별 프리셋 매핑을 불러옵니다.
  • 등록 직후 현재 로드된 액터를 모두 다시 판정합니다. 제외된 몸통 의상은 보정 판정에서 없는 것으로 취급하고, 어느 착용 슬롯이든 강제 보정 항목이 있으면 OBody NG와 같은 우선 동작을 유지합니다.
  • NPC 배포 가져오기와 OBody NG ORefit 등록은 독립적이므로 필요한 쪽만 사용하거나 둘 다 사용할 수 있습니다.
  • SlickSilk의 OBody Next Generation ORefit JSON Master List를 선택적 가져오기 소스로 지원합니다. 이 마스터리스트는 주로 OBody NG ORefit에서 제외해야 하는 의상 이름·플러그인 목록이며, BCNG는 이를 해당 의상을 가슴·유두 의상 보정 대상에서 제외하는 데 사용합니다. 목록에 강제 보정 항목이 포함된 경우에는 그 명시적 우선 동작을 유지합니다. JSON과 참조 프리셋 에셋은 별도로 설치해야 하며 BCNG 배포 파일에는 포함되지 않습니다.

호환 참고

  • Racial Skin Variance — 현재 RSV 그래프를 공급자로 사용하고 제한된 얼굴 브리지를 유지합니다. UBE 2.0 자체의 RSV 플레이어 제외(PLAYER VANILLA) 요구사항은 그대로 적용됩니다.
  • SOS·TNG·TRX·ERF — 외부 성기 지오메트리는 ActorBase 바디스킨과 분리된 액터 레퍼런스 단위·장비 인식 어댑터로 처리합니다.
  • Mu Dynamic NormalMap — 지원하는 노멀 동반 묶음을 선택 캐시 노멀과 함께 유지합니다.
  • OverlayFix — 액터 갱신과 비동기 작업 경계를 분리해 동시 사용 호환성을 높였습니다.

저장·소유권 범위

  • BodyMorph와 외부 성기 애드온은 액터 레퍼런스 단위입니다.
  • 네이티브 BodySkin은 NPC ActorBase 단위입니다. 같은 base를 공유하는 레퍼런스는 하나의 네이티브 스킨을 공유합니다.
  • 직접 선택과 평가된 NPC 결과는 현재 SKSE 코세이브에 속합니다.
  • 배포 규칙은 Data\SKSE\Plugins\BodyChangeNGdistribution.json에 별도 저장됩니다.
