Body Change NG v1.1.2

바디 · 스킨 · 플레이어 틴트를 하나의 인게임 UI에서 변경하고 NPC에게 조건 배포하는 네이티브 SKSE 모드

소개

Body Change NG는 BodySlide 바디 모프, 액터별 스킨 텍스처, 플레이어 RaceMenu 틴트 레이어를 한 화면에서 관리합니다. 플레이어와 현재 로드된 NPC를 직접 선택할 수 있고, NPC 배포 조건·세이브별 결과 저장·RaceMenu 종료 후 복원·OBody NG 규칙 호환까지 하나의 구조로 제공합니다.

실행 중 바디 메쉬를 교체하거나 NIF, Skin Armor, ArmorAddon, 장비 슬롯, OBody 원본 JSON을 수정하지 않습니다.

1.1.2의 주요 변경점

  • 블랙·그레이 인터페이스 — 창·패널·카드·입력칸·평상시 컨트롤은 검정·차콜·회색 바탕으로 통일하고, 선택·마우스 오버·경고·성공·진행 상태·즐겨찾기·틴트 미리보기의 기존 기능적 강조색은 유지합니다.
  • 간결한 액터 갱신 명칭 — 버튼을 한국어 액터 새로고침, 영어 Refresh actors, 중국어 刷新角色로 줄였으며 실제 로드 액터 갱신 동작은 그대로입니다.
  • 저장된 NPC 결과 복구 — 로드 후 저장된 바디·스킨을 액터마다 한 번 확인하고 없거나 깨진 결과만 다시 적용합니다.
  • 바디모프 중첩 방지 — 다른 모드의 모프 키를 삭제하지 않으면서 반복 미리보기와 배포가 프리셋의 절대 목표 체형에 도달합니다.
  • 다중 부위 스킨 연결 강화 — 몸·손·발·얼굴·성기와 종족·노인 조건부 부위를 올바른 채널에 연결하고, 의상 재구성과 부분 스킨팩에서도 유지합니다.
  • 호환성 확대 — 액터별 CBBE 3BA·UBE 2.0, 일반 남녀·SOS 스킨, 아르고니안·카짓, Racial Skin Variance, Mu Dynamic NormalMap과 OverlayFix 동시 사용 호환성을 강화했습니다.
  • 빠른 직접 적용 — 수동 선택을 우선하고 필요한 스킨 파일은 게임 스레드 밖에서 준비하며, 오래된 작업은 취소하고 자동 배포는 프레임 예산 안에서 처리합니다.
  • MO2 스킨 카탈로그 개선 — 실제 경로와 가상 Data 경로에서 같은 DDS를 두 번 해시하지 않으며 NPC 이벤트마다 DDS 전체를 읽지 않습니다.
  • 혼합 바디 해부학 옵션 안전화 — 의상 가슴·유두 보정과 NPC 유두·생식기 무작위화는 확인된 CBBE 3BA 액터에만 적용하고, UBE 액터는 명확한 인게임 안내와 함께 건너뜁니다.

OBody NG와 무엇이 다른가

두 모드 모두 최종 바디 변형에는 RaceMenu BodyMorph와 빌드된 TRI를 사용합니다. 따라서 Body Change NG도 별도 바디 메쉬를 갈아 끼우는 방식이 아닙니다. 차이는 그 위의 선택·배포·상태 관리 구조입니다.

  • MCM이 아닌 네이티브 GUI — F7로 여는 ImGui 창에서 플레이어와 로드된 NPC, 바디, 스킨, 틴트, 배포 규칙을 한 번에 관리
  • 액터에게 맞는 바디·스킨 목록 — CBBE 3BA와 UBE가 함께 설치되어도 MO2의 최종 승자 경로로 선택한 액터의 BodyFamily를 감지하고 해당 계열의 바디·스킨만 표시. 스킨은 인간형·아르고니안·카짓 종족과 여성·남성까지 액터별로 맞춤
  • 게임패드 탐색 — D-pad로 목록과 탭을 이동하고 기본·취소 버튼으로 선택과 닫기 지원
  • 즉시 미리보기와 확정 적용 분리 — BodyChangeNG, Preview, Outfit 전용 morph key를 분리하고 빠른 연속 선택에서 오래된 적용 작업이 뒤늦게 덮어쓰지 않도록 차단
  • 명시적인 배포 풀 — 폴더의 모든 프리셋을 자동 후보로 삼는 대신 각 규칙에서 사용할 바디와 스킨을 직접 선택
  • 바디·스킨 독립 제어 — 같은 규칙 안에서도 바디만 제외하고 스킨은 배포하거나, 반대로 스킨만 제외하고 바디는 배포 가능
  • 읽기 쉬운 우선순위 — 규칙을 위에서부터 평가해 처음 일치한 한 규칙의 바디·스킨 결정을 사용
  • 게임 안에서 배포 규칙 편집 — 조건, 성별, 우선순위, 바디·스킨 풀과 각 항목의 배포/제외를 네이티브 GUI에서 직접 편집
  • 즉시 배포 또는 다음 실행 — 편집값을 현재 로드된 NPC에게 즉시 재평가·배포하거나, 현재 세션은 유지하고 다음 게임 실행용으로만 저장
  • 세이브별 결과와 불필요한 재작업 억제 — 선택 결과와 적용 서명을 SKSE 코세이브에 보존하고, 바뀌지 않은 액터는 매 로드마다 전체 작업을 반복하지 않음
  • 통합 관리 — OBody NG의 바디 배포 범위를 넘어 액터별 스킨과 플레이어 틴트, RaceMenu 재진입 복원까지 같은 UI와 상태 구조로 처리
  • 즐겨찾기 — 바디 프리셋, 스킨팩, 틴트팩을 별표로 저장하고 즐겨찾기만 모아 보기

기존 메시 슬롯 방식과 무엇이 다른가

기존 메시 슬롯 방식은 미리 정한 슬롯마다 별도 바디 메시를 BodySlide로 출력하고, ESP에 준비된 Skin Armor·HeadPart·TextureSet을 Papyrus로 통째로 교체합니다. 따라서 스킨 세트를 쓰려면 해당 슬롯에 맞는 메시와 레코드도 함께 준비해야 합니다.

Body Change NG는 미리 정의된 ESP 바디 슬롯을 사용하지 않는 네이티브 SKSE 구조입니다.

  • 스킨과 메시를 분리 — Skin Armor, HeadPart, NIF를 세트마다 교체하지 않고 현재 액터가 실제로 로드한 바디·손·발·얼굴 파트의 텍스처 채널만 RaceMenu/NiOverride로 변경
  • 바디와 스킨을 자유롭게 조합 — 바디는 BodyMorph 프리셋, 스킨은 텍스처 오버라이드로 독립 적용하므로 같은 스킨에 다른 체형을 사용하거나 같은 체형에 다른 스킨을 사용 가능
  • 고정 CustomSet 슬롯 없음 — 미리 정의한 20개 ESP 슬롯 대신 설치된 XML 프리셋과 폴더형 스킨·틴트 카탈로그를 읽어 목록 구성
  • 게임 실행 중 추가 가능 — 실행 중 BodySlide XML 파일이나 스킨·틴트 폴더를 넣고 해당 탭의 새로고침을 누르면 재검색 후 바로 선택·적용
  • 플레이어와 NPC 모두 지원 — 직접 선택뿐 아니라 조건별 NPC 바디·스킨 배포와 세이브별 결과 유지 제공
  • 인게임 배포 편집·즉시 적용 — 게임을 종료해 설정 파일을 고치지 않고 조건과 풀을 편집한 뒤 현재 로드된 NPC에게 바로 배포
  • 틴트 직접 편집 — 플레이어 틴트팩 선택에 더해 레이어별 색상과 강도를 즉시 수정하고, Body Change NG가 변경하기 전 원본 값으로 레이어별 복원

주요 기능

바디

  • 플레이어 또는 현재 로드된 NPC에게 BodySlide 프리셋 즉시 적용
  • 액터 체중에 맞춰 Low/High Weight 값을 보간
  • 메뉴 선택 중 실시간 미리보기, 확정 적용, 의상 보정을 서로 다른 소유 morph key로 격리
  • 액터 바디 계열을 보수적으로 감지해 메인 바디 목록을 필터링
  • CBBE 3BA와 UBE는 같은 SliderPresets 폴더를 사용하며 XML 내부 Preset set과 Group 정보로 계열을 구분
  • 불확실하거나 여러 계열에 해당하는 프리셋은 안전하게 함께 표시
  • NPC 바디·스킨 규칙 풀은 모드 설정에서 선택한 여성·남성 NPC 바디 계열을 사용하며 실제 배포도 같은 계열만 선택
  • 미리보기·확정·NPC 반복 배포는 프리셋의 절대 목표 체형을 사용. 생략된 호환 슬라이더는 BCNG 소유 보정값으로 0을 목표로 하며 다른 모드의 키는 삭제하지 않음

스킨

  • 플레이어와 NPC별로 서로 다른 스킨팩 적용
  • 바디·손·발·얼굴·뱀파이어 얼굴 지원
  • 일부 파일만 있는 스킨팩도 지원: 존재하는 부위와 채널만 바꾸고, 없는 값은 액터의 기존 텍스처를 유지하며 몸·손·발·얼굴 파일을 서로 대신 사용하지 않음
  • 의상 또는 3D 재구성 뒤 선택 스킨을 확인·복구하고, 사망 NPC 장비 약탈 뒤 사라진 부위와 누락된 BCNG 캐시 파일도 원본 스킨팩에서 다시 준비
  • Diffuse, Normal, Subsurface, Specular, FaceGen Detail 텍스처 지원
  • UBE 2.0의 Body·Head d/n/sk 아틀라스를 별도로 감지하고, Body 아틀라스는 슬롯 32·53의 실제 UBE 몸과 손·발 지오메트리에, Head 아틀라스는 얼굴에 적용
  • 메인 바디스킨 목록은 선택 액터의 감지된 바디 계열만, NPC 규칙 목록은 모드 설정의 여성·남성 NPC 바디 타입만 표시
  • 아르고니안·카짓의 여성·남성 텍스처 폴더를 각각 감지하고 액터의 종족·성별에 맞는 스킨만 미리보기·재적용·NPC 배포하며, 해당 몸 아틀라스를 실제 꼬리 지오메트리에도 함께 적용
  • CBBE 3BA와 BHUNP/UNP 성기·항문 아틀라스를 해당 재질 지오메트리에만 연결하며 일반 바디 맵과 분리
  • 선택적 SOS Smurf Average·VectorPlexus Regular·Muscular 텍스처를 현재 애드온·종족·노인 재질에 맞춰 적용
  • femaleold·종족별 얼굴 노멀은 해당 파일이 있는 채널만 적용. Astrid·Afflicted 전용 텍스처와 BodySkin 안의 틴트마스크 DDS는 바디스킨 적용에서 제외
  • RaceMenu/NiOverride 영구 키를 사용하며 다른 모드의 키는 삭제하지 않음

플레이어 틴트

  • 여러 틴트팩 설치 및 선택
  • 플레이어 종족과 현재 레이어에 맞는 DDS 자동 선택
  • 게임 안에서 레이어별 색상·강도 값을 즉시 상세 조절
  • Body Change NG가 처음 변경하기 직전의 RaceMenu 원본 값으로 개별 복원
  • RaceMenu 종료 후 선택 팩·상세 값·복원 레이어 재적용

NPC 조건 배포

  • 위에서부터 평가하며 처음 일치한 규칙 사용
  • 바디와 스킨을 각각 배포 또는 배포 제외로 설정
  • 전체 NPC, 커스텀 팔로워, 노인, 플러그인, 종족, 팩션, 키워드, 클래스, 이름, NPC Base FormID 조건
  • 팩션·종족·키워드·클래스 대상은 플러그인+로컬 FormID로 저장하며 이름이 없는 레코드도 선택 가능
  • 한 개 선택 시 고정, 여러 개 선택 시 NPC별 안정적인 랜덤 결과
  • 기본 제외 8개 유지: 커스텀 팔로워·노인 남녀는 바디만, 아르고니안·카짓 남녀는 스킨만 제외
  • 규칙은 인게임 편집기가 Data\SKSE\Plugins\BodyChangeNGdistribution.json에 저장하므로 JSON을 직접 편집할 필요가 없습니다. 적용된 액터 결과는 SKSE 코세이브에 저장됩니다.
  • 로드 순서 변경 시 액터 참조 재해석, 변경 없는 NPC의 불필요한 재배포 방지
  • 게임 안에서 규칙을 편집하고 현재 로드된 NPC에게 즉시 배포하거나 다음 게임 실행용으로만 저장
  • 모드·Skyrim·MO2 프로필을 다시 설치할 때는 BodyChangeNGdistribution.json을 백업해 같은 경로로 옮기고 저장 값 불러오기를 누르면 기존 조건을 복원할 수 있습니다.

의상 보정·랜덤화

  • CBBE 3BA 액터의 의상 착용 시 가슴 보정 및 별도 유두 보정 옵션
  • CBBE 3BA NPC 전용 유두·생식기 형태의 안정적인 무작위화 옵션
  • UBE는 슬라이더 구성이 크게 다르므로 네 기능을 적용하지 않으며, UBE 액터 선택 시 인게임 안내와 툴팁을 표시합니다.
  • UBE 플레이어·CBBE NPC 혼합 환경에서도 전역 설정은 사용할 수 있고 실제 적용 여부는 액터별로 판단합니다.

UI·입력

  • 한국어·영어·중국어 UI
  • 기본 F7 메뉴 단축키를 모드 설정에서 변경할 수 있으며 Ctrl, Shift, Ctrl+Shift 조합도 지원
  • 마우스, 방향키/WASD, 게임패드 D-pad 탐색과 게임패드 선택·취소
  • 한글 IME, Backspace, 검색, 바디·스킨·틴트별 즐겨찾기와 즐겨찾기 모아 보기

필수 모드

  • Skyrim SE 1.5.97 또는 검증된 AE 1.6.x 런타임(1.6.1179까지)
  • 게임 버전에 맞는 SKSE64
  • Address Library for SKSE Plugins
  • RaceMenu BodyMorph/NiOverride

설치

  1. 메인 파일을 MO2로 설치합니다.
  2. 폴더 구조를 유지한 채 모드를 활성화합니다.
  3. SKSE로 게임을 실행하고 F7을 누릅니다.

바디 프리셋·스킨팩·틴트팩 추가

  1. 바디 프리셋 XML — MO2 모드 루트의 CalienteTools\BodySlide\SliderPresets\*.xml에 표준 BodySlide 프리셋 XML 파일을 넣습니다.
  2. 스킨팩 — 일반 CBBE 3BA/BHUNP/UNP 스킨은 BodySkin\<스킨팩 이름>\Textures\actors\character\... 구조를 사용합니다. CBBE 3BA 여성 팩의 femalebody_etc_v2_1.dds 및 _msn, _sk, _s 파일은 같은 아틀라스를 쓰는 3BA/3BBB의 성기·항문 지오메트리에만 적용합니다. BHUNP/UNP 팩은 원본 BakaUNP\VaginalAnalCanal2.dds와 같은 네 채널을 성기·항문·내부 지오메트리에만 적용합니다. 아르고니안·카짓은 같은 스킨팩 안에 원본의 argonianfemale, argonianmale, khajiitfemale, khajiitmale 폴더를 그대로 둡니다. UBE 2.0 스킨은 BodySkin\<스킨팩 이름>\Textures\!UBE\Body\femalebody_1_[d/n/sk].dds와 ...\!UBE\Head\femalehead_[d/n/sk].dds 구조를 유지합니다. 각 종족·성별 조합은 별도로 감지되어 맞는 액터에게만 표시됩니다.
  3. 틴트팩 — 틴트팩마다 TintMask\<틴트팩 이름>\textures\actors\character\character assets\tintmasks\*.dds 구조로 RaceMenu 틴트마스크 DDS를 넣습니다. 틴트마스크 방식만 호환되며, 오버레이 방식은 호환되지 않습니다. UBE 전용 팩은 최상위 틴트팩 이름에 UBE를 포함하고, COtR 표기 팩은 일반 여성·UBE 양쪽 호환으로 처리합니다.

위 경로는 모두 MO2 모드 루트 기준입니다. Body Change NG 메인 모드 안에 넣어도 되고, 같은 경로를 가진 별도 MO2 모드로 만들어 활성화해도 됩니다.

게임 실행 중에도 BodySlide 프리셋 XML 파일, 스킨팩 폴더, 틴트팩 폴더를 추가하거나 교체할 수 있습니다. 해당 바디프리셋·바디스킨·틴트마스크 탭을 열고 새로고침을 누르면 게임을 재시작하지 않고 파일을 다시 검색해 목록에 반영합니다.

남성 스킨은 BodySkin\<스킨팩 이름>\Textures\actors\character\male\...를 사용합니다. SOS 텍스처는 같은 팩의 Textures\actors\character\SOS\... 아래 원본 Smurf Average·VectorPlexus Regular·Muscular 폴더와 DDS 이름을 유지하고 해당 애드온을 별도로 설치합니다. 노인·종족 변형은 femaleold와 종족 폴더를 그대로 두면 되며, 누락된 부위나 채널은 원본을 유지합니다.

개인 프리셋·스킨·틴트는 메인 모드와 별도 MO2 모드로 관리하면 업데이트할 때 안전합니다. 각 에셋 폴더에는 설치 안내 README가 들어 있으며, 기본 배포 JSON은 schema 4이며 편집 가능한 샘플 제외 조건 8개가 포함됩니다. 기존 schema 3 파일도 읽을 수 있고 저장 시 새 형식으로 전환합니다.

선택적 OBody NG JSON 호환

OBody NG 형식의 배포 조건이나 의상 보정 규칙을 그대로 활용하고 싶은 사용자만 선택적으로 사용할 수 있습니다. OBody NG와 이 JSON이 없어도 Body Change NG 자체 기능은 정상적으로 작동합니다.

  • OBody Next Generation ORefit JSON Master List를 선택적 호환 소스로 지원합니다.
  • OBody NG 설정 파일은 자체 JSON과 같은 폴더의 Data\SKSE\Plugins\OBody_presetDistributionConfig.json에 둘 수 있습니다. 두 파일을 Data\SKSE\Plugins에 나란히 두며, BodyChangeNGdistribution.json을 덮어쓰거나 두 JSON을 합치거나 파일명을 바꾸지 않습니다.
  • OBody JSON은 시작할 때 자동으로 읽지 않습니다. 파일이 있으면 NPC 배포창의 저장 값 불러오기로 지원되는 OBody 배포 규칙을 가져오고, 의상·랜덤화 창의 OBody NG 의상 보정 규칙 등록으로 지원되는 의상 보정 데이터를 등록합니다.
  • OBody NG 규칙 중 필요한 것에 따라 배포 조건 가져오기만 실행하거나, 의상 보정 등록만 실행하거나, 둘 다 실행할 수 있습니다. OBody 원본 JSON은 읽기만 하며 수정하지 않습니다.

호환 참고

구형 BodyChange.esp를 제거한 뒤 남은 일반 RaceMenu 얼굴 참조는 인접 백업을 만들고 사용 가능한 High Poly Head 또는 바닐라 대상으로 복구합니다. UBE 커스텀 헤드 프리셋은 보존합니다. 스킨 기능은 맞는 텍스처 채널을 교체할 뿐, 없는 지오메트리를 만들거나 UV를 바꾸지는 않습니다.

Racial Skin Variance(RSV)와 함께 사용할 때 바디프리셋·틴트마스크 기능은 RSV와 독립적으로 작동합니다. RSV 액터에게 BCNG 바디스킨을 선택하면 액터의 실제 RSV Skin Armor를 대상으로 준비된 몸·손·발·얼굴·조건부 채널을 모두 적용합니다. RSV의 저장된 FaceGen 키 소유권은 유지하면서 BCNG가 선택한 얼굴을 현재 노드에 표시하고, RSV의 지연 노드 갱신 뒤 해당 액터만 한 번 합쳐서 재확인합니다. BCNG 스킨을 해제하면 RSV가 다시 자연스럽게 드러나며, BCNG 팩에 없는 채널은 RSV 또는 액터의 기존 텍스처를 유지합니다.

Mu Dynamic NormalMap의 normal detail·mask·overlay 동반 파일은 선택한 캐시 normal과 같은 묶음으로 유지해 재질 전체가 함께 갱신됩니다.

OverlayFix는 액터 갱신과 비동기 작업 경계를 정리해 동시 사용 호환성을 높였습니다.

크레딧 & 라이센스

Body Change NG는 GNU GPLv3 라이선스를 따릅니다. GitHub 저장소에서 소스를 공개하며, 빌드 스크립트와 일치하는 버전 태그도 함께 제공합니다. Nexus에는 MO2 설치용 Release ZIP만 제공합니다.

CommonLibSSE-NG, Dear ImGui, pugixml, nlohmann/json, SKSE64, Address Library for SKSE Plugins 및 RaceMenu 저자에게 감사드립니다. 자세한 서드파티 고지와 라이선스 전문은 배포 ZIP에 포함되어 있습니다. 모든 저작권과 권리는 각 원작자에게 있습니다.
