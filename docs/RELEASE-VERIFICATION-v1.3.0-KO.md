# Body Change NG 1.3.0 — 수정 및 회귀 검증

검사일: 2026-09-19~20. 비교 기준: 1.2.9 (`747de9b06bac5a7c74525cd5bf9a554cd932e6cd`).

## 수정 범위

[1.2.9 정밀 검사](PRECISION-FUNCTIONAL-AUDIT-v1.2.9-20260919-KO.md)의 세 경로와 [1.3.0 재점검](PRECISION-FUNCTIONAL-AUDIT-v1.3.0-20260919-KO.md)의 추가 세 경로를 수정했다. 기존 기능을 광범위하게 재작성하거나 엔진 폼 해제 정책을 바꾸지는 않았다.

1. **복수 오버레이 복원:** 지연 쓰기 전에 작업 내부에서 슬롯을 예약한다. 성공한 기존 슬롯을 먼저 확보하고 미배정·범위 밖·중복 슬롯을 나중에 배정한다. 색상, 액터 호환성 확인, 외부 슬롯 소유권 검사는 유지한다. 예약 벡터와 지연 항목 참조는 한 작업 안에서만 사용한다.
2. **기본 바디와 의상 보정:** 자동 바디 검증에서 별도 의상 보정 키를 바디 불일치로 보지 않는다. 실제 기본 바디 복구가 필요하면 기존 정리 후 정상 의상 정책으로 재평가한다. 바디 정리는 보정 서명도 무효화하여 이후 장비/SFS 판단이 이전 성공 기록으로 건너뛰지 않도록 한다. 명시적 초기화·삭제 준비는 기존 소유 값 제거 정책을 유지한다.
3. **RaceMenu 중 스킨 취소 복원:** 언로드 취소에 살아남는 복원 작업에 대상 액터와 세션 식별 정보를 둔다. 플레이어의 RaceMenu 편집 중에는 같은 작업을 큐에 보류하고 닫힌 뒤 재개한다. 비동기 텍스처 준비 후속 작업도 같은 정보로 보류하며 이전 세션의 후속 작업은 거부한다. 기존 ActorBase 요청 세대 검사는 유지하여 새 선택을 오래된 취소가 덮어쓰지 않도록 한다.
4. **바디 취소/액터 전환 정리:** 바디 미리보기 정리 채널도 동일한 RaceMenu 보류를 사용한다. 미로드 상태의 키 정리, 새 활성 미리보기 보호, 세션 검사는 유지한다.
5. **오버레이 취소 보존:** 부위별 복원은 기존 액터 FIFO와 동일 채널 최신 선택 교체를 유지하면서 메뉴 진입/언로드 취소에 살아남는다. 실행된 복원의 지연 쓰기도 같은 lease로 직렬화한다. 새 일반 작업으로 교체되면 복원의 취소 면제 속성은 남기지 않는다.
6. **기본 바디 플레이어 복원:** 로드/RaceMenu 종료의 기본 바디 정리 다음에 기존 OutfitRefit 정책을 예약한다. 일반 초기화/삭제 준비 함수에는 재보정을 추가하지 않았다. 비활성화·누드·SFS 대기/부재·지정/자동 보정 분기는 그대로 사용한다.

README의 검사 수 안내도 34개로 맞췄다. 새 전용 스레드·영구 상태 맵·저장 필드는 추가하지 않았다.

바디 보정 수식·모프 보존 옵션·배포 조건·저장 형식·기존 지원 12개 SE/AE 런타임·RaceMenu ABI·의존성 잠금은 변경하지 않았다. 1.7.x와 VR 지원은 추가하지 않았다.

### 새 결함의 회귀 대조

- 미배정 오버레이 3개가 0/1/2 슬롯으로 복원된다. 기존 슬롯, 미배정/범위 밖 혼합, 중복 슬롯 뒤 정상 슬롯, 잘못된 항목 뒤 정상 소유 슬롯, 외부 점유, 색상 유지, 네 부위의 용량 0/1/2를 검사한다.
- 기본 바디의 의상 보정 키만 있으면 정상으로 판단하고 정리/재계산을 예약하지 않는다. 반대로 기본·미리보기·이전 버전·OBody/OClothe 바디 키가 남아 있으면 정리와 의상 재평가를 예약한다. 기존 명시적 제거 정책도 검사한다.
- 실제 제품 Pump에서 RaceMenu가 열렸을 때 복원은 실행되거나 폐기되지 않고 닫힌 뒤 재개된다. `CancelActor` 후에도 유지된다. 장시간 보류, NPC 복원 병행, 새 선택, 취소된 후속 작업, 비동기 후속 작업, 세션 초기화도 큐 검사에 포함한다.
- 오버레이 네 부위의 취소/저장 복원, 취소 직전 대기 미리보기 제거, 새 미리보기·색상·확정·초기화의 채널 교체를 확인한다. 실행 중 복원의 후속 쓰기가 끝나기 전 새 선택을 실행하지 않는다.
- 바디 정리 반복 10,000회는 한 작업으로 병합되며 미로드 키만 정리한다. 플레이어 편집 중 NPC 복원은 계속된다. 기본 바디 복원은 실제 정리 뒤 의상 키를 다시 적용하고 삭제 준비/명시적 초기화는 그렇지 않음을 확인한다.

## 검증 한계 및 배포 상태

이 검사는 게임 실행·게임 메모리 변경·세이브 조작 없이 수행했다. 엔진/GPU 전체 메모리, 실제 얼굴 합성, 모든 지원 런타임과 모드 조합의 렌더링은 검증한 것이 아니다. 성공한 장기 유지 폼은 검사기가 정리하며, 실제 제공자가 보유할 수 있는 ARMO/ARMA/TXST를 무작정 해제하지 않는 기존 정책은 유지한다. VM이 이미 실행 중인 호출을 선점하거나 외부 콜백 객체를 강제로 회수하지도 않는다.

소스·문서와 로컬 Release DLL을 1.3.0으로 정리했다. `scripts/Package-Release.ps1`은 커밋된 소스로부터 `release` 루트에 릴리즈/소스 ZIP을 만들고 모든 엔트리 해시를 검증한다. 배포 ZIP은 DLL·빈 배포 규칙·폴더 안내 3개·필수 라이선스 2개로 제한하며 PDB는 제외한다. 소스 ZIP에는 고정 의존성과 SOURCE-REVISION을 포함한다. MO2 교체와 새 인게임 테스트는 수행하지 않았다.
