# v1.3.7 릴리즈 검증 — 2026-10-17

## 변경 범위

- 전체 NPC 규칙의 기본값 켜짐 ‘어린이 제외’를 바디프리셋·바디스킨·후타스킨·오버레이에 추가했다. 기존 규칙에서 필드가 생략되어도 제외한다. 다른 명시적 대상 범위의 판정은 유지하며, 이미 적용된 외형을 자동 복원하지 않는다.
- schema 3~7의 배포 JSON 자동 변환 전에 읽기 핸들을 닫아 같은 파일 교체 시 접근 충돌을 제거했다. 상세 오류 팝업이나 저장 API 변경은 포함하지 않는다.
- 이전 개발 변경인 RaceMenu 체형 편집 연결, 오버레이 상태 안내, BCNG 소유 몸·손·발 텍스처 확인과 제한된 복구를 포함한다. 공개 1.3.6은 교체하지 않는다.

## 검사 결과

새 `build/v1.3.7/tests`의 회귀 실행 파일 **50/50 통과**. 이전 버전의 남은 실행 파일이나 별도 조사용 Probe는 집계하지 않았다. 파일 교체·잠금·하드링크 검사는 작업 폴더 안의 별도 임시 자료로 실행했다.

- 어린이 제외: 기본값, 기존 규칙 생략값, ON/OFF 저장·취소, 다른 범위 유지, 네 기능 탭, 한·영·중 9개 언어/배율 배치 검사.
- 배포 저장: 88개 범위/성별/기능 조합, 동일 경로 schema 3~7 변환, 닫힌 읽기 핸들, 원문 백업·주석 보존, 25회 재저장, 원자적 교체·실패 후 재시도.
- RaceMenu 편집: 실제 제품 함수를 통한 60,101개 검사 및 60,000회 재개방. 다른 공급자 모프, 편집 중 저장·복구, 초기화·취소 포함.
- 스킨 리소스: 실제 제품 함수를 통한 100,271개 검사 및 50,000회 복구 수명. 실패 횟수 제한, 외부 소유권, 이전 캐시, 세대 변경, detach/reset 정리 포함.
- 기존 런타임 12개와 BodyMorph v4/v5 ABI, 모프 수치·체중 보간, 입력·휠, 미리보기 복원, 배포·스킨·오버레이 회귀 검사 통과.
- PowerShell 배포 작성 도구 검사와 기존 소개글 테마 대비 검사 108개 통과.
- `git diff --check` 통과. 의존성 잠금 파일의 내용 변경 없음.

RaceMenu ExtraData 테스트의 공개 픽스처 51,245개 검사는 통과했다. 해당 실행의 선택적 외부 DLL 이미지 검사는 별도 DLL 인수를 주지 않아 실행하지 않았다.

## 패키징

`scripts/Package-Release.ps1`로 깨끗한 커밋에서 배포 ZIP과 소스 ZIP을 생성한다. DLL 버전, 배포본 11개 파일, 비활성 기본 규칙, 필요한 소스 의존성·라이선스, 모든 ZIP 항목의 SHA-256을 대조한다. 소스 ZIP에 `SOURCE-REVISION.txt`를 넣고 두 ZIP의 SHA256SUMS를 함께 배포한다.

## 검증 범위

이번 릴리즈 검사는 오프라인 빌드·회귀 검사다. 제보자 환경의 저장 실패 원인을 확정한 것으로 표현하지 않는다. 게임·세이브·MO2 설치본은 이번 릴리즈 작업에서 변경하지 않았다. 한·영 사용자 변경 내역은 [릴리즈 노트](RELEASE-NOTES-v1.3.7.md)에 정리했다.
