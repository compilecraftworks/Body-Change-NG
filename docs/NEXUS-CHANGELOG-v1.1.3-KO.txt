Body Change NG 1.1.3 — 2026-09-06

1.1.2의 모든 변경사항을 포함합니다.

- 네이티브 UI 전체의 창·패널·팝업·제목 표시줄·평상시 컨트롤·입력칸·카드·표·스크롤바·크기 조절 손잡이·탐색 영역을 검정·차콜·회색 바탕으로 통일하고, 선택·마우스 오버·경고·성공·진행 상태·즐겨찾기·비호환 안내·실제 틴트 미리보기의 기능적 강조색은 유지했습니다.
- 주변 액터 목록 갱신 버튼을 한국어 `액터 새로고침`, 영어 `Refresh actors`, 중국어 `刷新角色`로 줄였으며 실제 동작은 바꾸지 않았습니다.
- 메인 탭 이름을 `바디프리셋`, `바디스킨`, `틴트마스크`로 통일하고, 빈 목록에는 정확한 설치 경로와 새로고침 방법을 한국어·영어·중국어로 안내합니다.
- 틴트마스크 방식만 호환되며 오버레이 방식은 호환되지 않는다는 안내를 UI·동봉 안내문·넥서스 설명에 추가했습니다.
- 동봉 기본 배포 규칙 8개의 이름을 영어로 변경했습니다. 사용자가 작성한 기존 규칙 이름은 바꾸지 않습니다.
- 규칙별 바디 계열 드롭다운을 제거했습니다. NPC 규칙의 바디·스킨 풀은 모드 설정에서 지정한 여성·남성 NPC 바디 타입을 사용하며 편집기에 실제 적용 계열을 글자로 표시합니다.
- 새 규칙 대상에서 전투 스타일을 제거하고 종족·팩션·키워드·클래스 등의 상세 선택 목록이 아래쪽으로 열리게 했습니다.
- 바디스킨 목록은 선택 액터의 감지된 바디 계열만 표시하고, NPC 배포 스킨 목록은 설정에서 지정한 여성 또는 남성 NPC 바디 타입만 표시합니다.
- 의상 착용 시 가슴·유두 보정과 안정적인 NPC 유두·생식기 무작위화는 확인된 CBBE 3BA 액터에만 적용합니다. UBE와 불확실한 여성 계열은 현지화 안내와 함께 건너뛰며 UBE 플레이어·CBBE NPC 혼합 환경의 NPC 설정은 유지됩니다.
- UBE 의상이 몸 피부를 슬롯 32와 슬롯 53에 나누어 가진 경우 두 지오메트리를 함께 갱신하고 UBE Body 아틀라스를 몸·손·발에 일관되게 적용합니다.
- CBBE 3BA·BHUNP·바닐라·UBE BodySkin의 각 채널을 부위별 정확한 ArmorAddon과 로드된 지오메트리에 적용합니다.
- RaceMenu의 넓은 스킨 슬롯 호출 때문에 마지막 발 적용값이 손까지 덮어쓰던 문제를 수정했습니다. 일반 바디 계열의 발은 의도한 몸 아틀라스를 사용하고 손은 전용 손 텍스처를 유지합니다.
- 몸·손·발 텍스처를 서로 분리된 단일 비트 RaceMenu 스킨 슬롯에 저장하고 정확한 의상 노드 갱신을 주 표시 경로로 유지하여 착의·탈의 부위가 서로 독립적으로 기본 스킨으로 돌아가지 않게 했습니다.
- SFS가 장비를 화면에서 숨겨도 실제 Biped 슬롯을 계속 점유하는 경우를 처리합니다. 현재 없는 부위에만 영구 대체 경로를 저장하고 정확히 보이는 부위를 다시 복구하여 부위 간 덮어쓰기를 막습니다.
- 플레이어/NPC 수동 선택, NPC 직접 지정, 조건 배포, 장비 변경, 사망 NPC 약탈 뒤 복구가 모두 같은 다중 부위 수정 경로를 사용합니다.
- 부분 스킨팩은 실제 존재하는 부위·채널만 바꾸며, 없는 파일은 액터의 기존 텍스처를 유지합니다. 몸·손·발·얼굴 파일을 다른 부위로 복제하지 않습니다.
- 기본 스킨 복원 시 BCNG 소유 RaceMenu 키뿐 아니라 이미 로드된 BCNG 클론도 정리합니다. 명시적인 기본 스킨 선택은 장비 변경 뒤에도 유지하고 구버전 의상 키는 해당 액터에서만 제거합니다.
- 기존 세이브의 배포 NPC도 새 세션에서 한 번 확인하고 실제 바디·스킨 결과가 없거나 불완전한 경우에만 저장된 선택을 다시 적용합니다.
- 바디모프 미리보기·확정·배포를 반복해도 다른 모드 소유 모프 키를 전부 지우지 않으면서 선택한 XML 프리셋의 절대 목표 체형으로 수렴합니다.
- 성기·항문 아틀라스, 종족·노인 얼굴 변형, 아르고니안·카짓 남녀 자산, SOS 텍스처와 부분 채널을 정확한 액터·부위·재질별로 분리해 처리합니다.
- 구형 SE Override v0, UBE의 AE 역포트 Override v0, 정식 v1, 정식 v2를 별도 판정합니다. v0/v1은 직렬화에 안전한 Papyrus 경로를 사용하고 검증된 v2만 native 인터페이스를 사용합니다.
- Racial Skin Variance, Mu Dynamic NormalMap, OverlayFix와의 동시 사용 호환성을 높이고 다른 모드 소유 키를 지우지 않습니다.
- 수동 선택을 우선하고 필요한 스킨 파일은 게임 스레드 밖에서 준비하며 오래된 작업은 취소하고 자동 배포는 프레임 예산 안에서 처리합니다.
- 실제 경로와 MO2 가상 Data 경로에서 같은 DDS를 중복 해시하지 않습니다. 상시 파일 검색·전체 NPC 반복 검사·이벤트마다 DDS 전체 읽기는 추가하지 않았습니다.
- Release 빌드와 회귀 테스트 실행 파일 12종을 모두 통과했습니다.
