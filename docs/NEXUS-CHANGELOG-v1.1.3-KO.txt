Body Change NG 1.1.3 — 2026-09-06

- CBBE 3BA·BHUNP·바닐라 BodySkin의 몸·손·발을 정확한 ArmorAddon과 로드된 지오메트리에 각각 적용하도록 수정했습니다.
- RaceMenu의 넓은 스킨 슬롯 호출 때문에 마지막 발 적용값이 손까지 덮어쓰던 문제를 수정했습니다. CBBE 계열 발은 몸 아틀라스를 사용하고 손은 전용 손 텍스처를 유지합니다.
- SFS로 화면에서 숨긴 신발이 실제 Biped 슬롯을 계속 점유하는 경우도 처리합니다. 현재 없는 부위에만 1비트 영구 키를 저장하고, 보이는 정확한 부위가 다른 부위 텍스처로 다시 칠해지지 않게 복구합니다.
- 플레이어/NPC 수동 선택, NPC 직접 지정, 조건 배포, 의상 착탈·사망 NPC 약탈 뒤 복구가 모두 같은 수정 경로를 사용합니다.
- 기존 세이브의 배포 NPC도 새 세션에서 실제 몸·손·발 상태가 다르면 선택 스킨을 한 번 다시 적용합니다.
- 구형 SE Override v0, UBE의 AE 역포트 Override v0, 정식 v1, 정식 v2를 별도 판정합니다. v0/v1은 직렬화에 안전한 Papyrus 경로를 사용하고, 검증된 v2만 native 인터페이스를 사용합니다.
- UBE 공용 아틀라스 경로와 기존 규칙·설정·JSON·코세이브·부분 스킨·기본 스킨 복원 기능은 유지합니다.
- 상시 파일 검색이나 전체 NPC 반복 검사를 추가하지 않았습니다. 누락 부위 보완은 실제 스킨 적용 중에만 실행하고 노드 재구성도 한 번으로 합칩니다. Release 빌드와 회귀 테스트 12종을 모두 통과했습니다.
