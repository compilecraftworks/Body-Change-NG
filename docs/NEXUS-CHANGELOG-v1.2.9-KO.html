미리보기 복원 수정

  • NPC 언로드 후 스킨 미리보기 취소 시 원래 스킨을 복원합니다. 액터를 강제로 로드하지 않으며, 새로운 미로드 선택의 지연 적용은 유지합니다.
  • 확정된 BCNG 액터 기록이 없어도 언로드된 오버레이 미리보기를 정리합니다. 배포 체크박스 누적 미리보기도 포함하며 새 선택과 확정 색상은 보존합니다.
  • 몸과 얼굴 정리가 모두 성공해야 기본 스킨 복원 완료로 기록합니다. 일부 실패 시 재시도 정보를 유지합니다.

수정 범위와 검사

기존 기능·저장 형식·의존성·SE/AE 지원 범위는 유지합니다. 새 영구 캐시나 상시 스캔은 추가하지 않았습니다.

Release 빌드와 오프라인 회귀 실행 파일 32개 통과. 언로드/취소 10,000회 검사를 포함하며 새 인게임 테스트는 수행하지 않았습니다.
