# Body Change NG 1.1.4

배포일: 2026년 9월 6일  
이전 공개 버전: 1.1.3

[English release notes](https://github.com/compilecraftworks/Body-Change-NG/blob/v1.1.4/docs/RELEASE-NOTES-v1.1.4.md)

## 수정 사항

- NPC의 바디·의상·3D 갱신 뒤 바디스킨이 잠깐 나타났다가 원래 스킨으로 되돌아가던 문제를 수정했습니다.
- 자동 스킨 배포는 액터 재구성이 안정될 때까지 기다린 뒤 최종 Biped 복제본을 한 번 다시 칠합니다.
- NPC에게 직접 고른 바디스킨과 기본 스킨은 즉시 잠기며 자동 배포가 덮어쓰지 않습니다.
- 몸·손·발·얼굴·생식기·항문 텍스처 경로를 서로 분리했습니다. 없는 파일은 액터의 기존 텍스처 채널을 유지합니다.
- 이미 사망한 상태로 로드된 NPC도 바디·스킨 배포 대상이 되어 Zeroed Sliders에 남지 않습니다.

## NPC 배포 편집기

- X·Escape·메인 창 닫기로 배포창을 종료해도 편집한 다음 실행용 초안을 자동 저장합니다.
- 같은 세션에서 배포창을 다시 열면 초안을 유지하고, 세이브 로드 경계에서는 메모리 초안을 지워 다른 세이브로 새지 않게 합니다.
- 바디프리셋·바디스킨 후보 목록에 현지화된 **전체 선택**과 **전체 해제** 기능을 추가했습니다.
- 저장한 편집값은 **저장 값 불러오기** 또는 **로드된 NPC 즉시 배포**를 눌러야 현재 세션에서 활성화됩니다.

## 성능과 호환성

- 프레임마다 JSON을 쓰거나 폴더를 다시 검색하거나 NPC를 계속 감시하는 처리는 추가하지 않았습니다.
- 스킨 재적용은 변경 대상 액터와 최종 재구성 복제본에만 제한됩니다.
- 기존 CBBE 3BA, BHUNP/UNP, UBE, HIMBO, SAM, 바닐라, SOS/TNG, RaceMenu 버전 라우팅, RSV/Mu Dynamic NormalMap 처리와 OverlayFix 호환 경계를 유지했습니다.
