## 변경

- `RaceMenuOverlay.cpp`: BCNG가 이미 선택/슬롯/경로/색상을 추적 중이며, 관련 RaceMenu 저장 키가 모두 비어 있고, 현재 로드된 양쪽 뷰의 해당 노드 DDS/색상/불투명도가 마지막 BCNG 값과 일치할 때만 저장 키를 복구한다.
- 다른 텍스처, 변경된 색상/알파, 기존 scalar override, 추적하지 않은 슬롯, 없는 노드는 복구하지 않는다. 임의 슬롯 할당이나 다른 모드 슬롯 삭제로 우회하지 않는다.
- v1은 실제 라이브 노드에서 RaceMenu가 intern한 문자열을 읽어 등록한다. v2는 공개 등록 인터페이스 사용. 이 복구 단계에서 DDS 재업로드/지오메트리 복제/3D 재구축을 하지 않는다.
- 교체, 색상 변경, 저장 상태 기본값 복원, 미리보기 기본값 복원 모두 같은 검사 경로를 사용한다. 색상 변경은 **변경 전 색상**으로 소유권을 먼저 확인한다.
- Geometry/Material 원시 포인터를 저장하지 않는다. 재시도 루프/폴링/추가 장기 상태 맵/VM handle pin을 추가하지 않는다.
- `OverlayPolicy.h`: 복구 허용 조건, 색상/알파 비교, 원본 얼굴 shader feature 판정을 테스트 가능한 함수로 분리했다.
- 얼굴 원본 판정은 Native FaceGen(4) 및 RGBTint(5)를 허용하고 기존 Face [Ovl]/[SOvl] 노드는 원본으로 보지 않는다. 이전에는 5만 허용했다.
- 라이브 검증 로그에 VM handle, shader feature, cull 상태, 실제 RGB를 추가했다. 색상 변경 후에도 검증한다. 얼굴의 실제 표시 문제와 메타데이터 정지를 구분하기 위한 진단이며 hidden node를 강제로 표시하지 않는다.
