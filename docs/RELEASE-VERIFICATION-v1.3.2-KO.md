# Body Change NG 1.3.2 — NPC 직접 스킨 선택·얼굴 처리 검증

검사일: 2026-09-24. 비교 기준: 1.3.1 (`7a3c92b87613d0a61f7d48822fa62262e9f2d0bc`).

## 포함한 수정

- 바디 계열 미확인 액터의 직접 스킨 선택을 자동 배포와 구분한다. 규칙 없이 클릭 미리보기·더블클릭 적용을 지원한다. 성별·종족·확인된 계열 간 비호환 제한과 자동 배포의 호환성 검사는 유지한다.
- 정확한 계열을 모를 때 일반 스킨의 몸·손·발은 원래 부위별 대상으로 적용하고, CBBE/UNP 성기·항문 보조 아틀라스는 추측하여 적용하지 않는다. UI에서 올바른 일반/UBE 팩 선택이 필요하다고 안내한다.
- 저장된 수동 선택 재적용, 미리보기 복원, 플레이어 RaceMenu 후 재적용에 직접 선택 의도를 전달한다. 내부 DDS 경로로 원래의 미확인 계열을 다시 추측하지 않는다.
- NPC 얼굴의 HeadPart 이름과 실제 geometry 이름이 달라도 실제 FaceGen 영역에서 명확한 얼굴 대상을 찾는다. 이름 우선순위·재질·중복 후보·얼굴 밖 동명 객체를 검사한다.
- 얼굴 DDS와 이전 얼굴 복원 상태가 모두 없는 몸 전용 팩은 얼굴 타깃을 기다리지 않는다. 몸 재생성 완료 확인 및 필요한 얼굴 복원은 유지한다.
- 새 프레임 폴링, 추가 게임 폼 복제 경로, 캐시 형식·세이브 스키마·의존성·지원 런타임 변경은 없다. 1.3.1의 캐시 정리 도구와 경로 보존 정책은 유지한다.

개발 중 분석과 1.1.4 비교는 [점검 기록](NPC-DIRECT-SKIN-AUDIT-20260924-KO.md)에 남겼다.

## 빌드와 검사

- 고정된 xmake 3.1.0, vendored CommonLibSSE-NG 6.7.1 및 기존 잠금 의존성으로 Release 전체 빌드 성공. SE·AE 전용이며 VR 빌드를 추가하지 않았다.
- `build/v1.3.2/tests/*Tests.exe` **35개 모두 통과**. 바디/UBE·스킨/후타·오버레이/틴트·배포/저장·입력·SFS/보정·복원·캐시·런타임 경계의 기존 검사도 재실행했다.
- `tools/test-addon-audits.py` **19개 통과**.
- 직접/자동 선택 정책을 5개 레이아웃 × 2개 성별 × 3개 종족 × 128개 계열 마스크로 비교했다. 알려진 계열에 대한 기존 제한과 성별·종족 필터를 우회하지 않는지 검사했다.
- 실제 제품 `ResolveNodeName` 함수에 가짜 엔진 경계를 연결하여 NPC 얼굴 이름 불일치, 정확한 이름 우선, HeadPart 부재, 여러 후보, 얼굴 밖 동명 몸 geometry, 미로드·미지원 런타임을 검사했다.
- 실제 제품 `SourceBodyFamily` 함수로 미확인 값 유지, 종족·성별·외부 공급자 변경 시 무효화를 검사했다. 직접 선택 의도가 복원 호출까지 전달되는지 검사했다.
- 일반 팩의 손·발 개별 DDS 경로, 계열 미확인 시 보조 아틀라스 차단, 부분 얼굴/몸 전용 팩의 얼굴 필요 여부를 검사했다. 기존 언로드·새 선택·세션 변경·실패 복원 검사도 통과했다.
- `git diff --check` 통과. 한영 Markdown·Nexus 영문 BBCode/일반 텍스트·한글 HTML/일반 텍스트를 갱신했다.

## 검증 한계

새 인게임 테스트나 제보자 환경 재현은 수행하지 않았다. 위 코드상 실패 경로는 수정했지만 모든 NPC 스킨 문제의 원인이 동일하다고 단정하지 않는다. 실제 UV가 다른 팩이나 외부 스킨 컨트롤러 간 충돌까지 해결하는 변경은 아니다. 전체 게임/GPU의 누수 부재를 보증하는 검사는 아니다. 이번 배포 작업은 MO2 설치나 기존 세이브·스킨팩·캐시를 변경하지 않는다.
