# Body Change NG v1.2.1

## v1.2.0 대비 변경

- 배포 도구 행: 여성 / 남성 / 배포 하기 / 배포 취소, 기본은 여성. 해당 성별의 가까운 NPC를 선택하고 없으면 플레이어를 선택합니다. 후타는 등록된 여성 후타 NPC만 선택합니다. 목록·새 규칙 성별을 미리보기 액터와 분리하고 바디·스킨에 설정된 배포 바디 타입을 반영합니다. 성별 전환 시 이전 선택·미리보기를 정리합니다. NPC 배포 체크박스 모드의 자동 미리보기 액터 선택에서는 후타를 포함해 커스텀 팔로워·노인 NPC를 제외합니다. 일반 액터 직접 선택과 실제 배포 규칙은 바꾸지 않습니다.

- 후타스킨 즐겨찾기를 일반 목록과 NPC 배포 목록에 추가하고 설정 저장을 연결했습니다. ERF·TRX·UBE TRX 항목은 각각 구분합니다.
- 프리셋 확정·자동 바디 적용·기본 바디 복원 시 `OBody`와 `OClothe` 키를 제거합니다. **다른 모드의 모프 보존**을 켜도 두 키는 삭제하며, 그 외 키는 보존 옵션을 따릅니다. 전체 초기화에서도 기존 BCNG 관리 대상에 같은 정리 범위를 적용합니다.
- 미리보기는 키 제거 후 결과만 보여주고 취소하면 원래 상태를 복원합니다. 기본 복원 미리보기의 모프 순회는 4회에서 1회로 줄였습니다.
- 기존 세이브의 BCNG 바디는 새 정리 정책으로 한 번 재평가합니다. ASTR 코세이브는 버전 6을 유지하며 별도 구버전 계산 모드를 추가하지 않았습니다.

## 업데이트 방법

1. 게임을 종료하고 세이브와 같은 이름의 `.skse` 코세이브, 설정·사용자 규칙·에셋 팩을 백업합니다.
2. BCNG DLL을 v1.2.1로 교체하고 활성 DLL은 하나만 유지합니다. `Data\SKSE\Plugins\BodyChangeNG\settings.json`, 사용자 배포 규칙과 기존 팩은 보존합니다. 규칙을 배포본의 빈 시작 파일로 덮어쓰지 마세요.
3. 기존 세이브를 로드해 체형을 확인합니다. 이번 업데이트만을 위해 새 게임이나 세이브 정리를 할 필요는 없습니다. OBody 모프를 명시적으로 정리하려면 프리셋 또는 기본 바디를 확정합니다.

실행 중인 OBody의 자체 재배포를 끄는 기능은 아닙니다. 같은 액터의 체형을 두 시스템이 계속 재지정하지 않도록 설정하세요. 메시의 Zeroed Sliders·Build Morphs 준비는 여전히 필요하며, 키 정리로 메시 자체에 구워진 체형을 바꿀 수는 없습니다.
