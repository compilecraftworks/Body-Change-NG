# v1.3.3 이름 기반 배포 JSON 검증

검증일: 2026-09-24. 로컬 구현과 오프라인 검증이며 인게임 적용·배포 게시 완료를 뜻하지 않습니다.

## 구현

- schema 8: sex/scope와 프리셋·스킨·후타·오버레이 후보를 이름으로 작성합니다. 종족·팩션·키워드·클래스·전투스타일·NPC Base 대상은 고유 EditorID/표시 이름 또는 플러그인 한정을 지원합니다.
- 같은 이름의 후보는 기존 액터 호환성 검사 후 정확히 하나로 좁혀질 때만 적용합니다. 없는/모호한 이름은 저장에서 유지하고 다른 항목을 임의 선택하지 않습니다. 일부 레코드가 이름을 제공하지 않을 때만 플러그인+로컬 ID 표기를 사용합니다.
- 내부 ID와 기존 호환 조건/선택 해시는 유지합니다. JSON 이름을 실제 카탈로그 ID로 해석한 뒤 기존 적용 경로에 전달합니다. 후보 순서·중복 가중치와 오버레이 원본 색상 키를 보존합니다.
- 카탈로그 변경 때만 이름 색인을 다시 만들고, 호환성 검사는 후보 묶음당 한 번 합니다. 프리셋 슬라이더를 이름 색인에 복제하지 않습니다. 엔진 포인터를 저장하지 않는 대상 스냅샷을 DataLoaded에서 생성하며 UI 저장·NPC마다 폼 배열을 순회하지 않습니다.
- schema 3~7은 백업 후 변환합니다. 기존 제외 규칙 제거 등 원래 마이그레이션을 유지합니다. 당시 무시되던 enabled는 true로 변환하며 schema 8부터 false가 실제 비활성화로 동작합니다.
- 기존 ID를 정확히 설명할 수 있는 경우만 이름+구분자로 바꿉니다. 이름 미설치·중복·빈 이름·비정상 UTF-8·길이 초과 등은 기존 ID로 보존합니다.
- 원본 .schemaN.bak 또는 번호 붙인 백업을 먼저 만들고 원자적 저장을 진행합니다. 기존 백업은 덮지 않습니다. 활성 JSON은 위, 주석/예시는 아래에 유지됩니다.
- 고급 대상의 label은 설명 전용 필드에 보존하며 이름 매칭 대체값으로 사용하지 않습니다. 인게임 대상을 새로 선택할 때 옛 이름 참조·메모를 지워 이전 대상으로 되돌아가지 않게 합니다.
- 주석 지원은 배포 JSON에만 적용합니다. co-save, 게임 런타임 표, RaceMenu ABI, 의존성 고정과 SE/AE 전용 빌드는 바꾸지 않았습니다.

## 검사

- Release DLL 빌드 및 기존 회귀 실행 파일 35개 + 새 이름 작성 검사 1개(총 36개).
- 실제 schema codec의 모든 11개 범위 × 성별 × enabled 상태, 모든 기능 후보와 이름/색상 재저장.
- schema 3~7의 실제 ID와 플러그인/로컬 ID 유지, 구 enabled 동작, 미설치 ID 보존.
- 제품의 ReadableRules/ResolveNamedTarget 함수를 그대로 추출해 고정 스냅샷으로 실행: 바디/스킨/후타/4부위 오버레이를 이름으로 변환→저장→재로드→원래 ID·색상 확인. 반복 변환 동일성, 모호한/없는 대상의 낡은 runtime ID 제거.
- EditorID 우선, 표시 이름 중복, 플러그인 한정, 성별 등 기존 호환 함수로 좁히는 이름 선택, XML 파일 구분, 누락된 에셋, 이름의 공백·대소문자, 잘못된 필드/범위/색상/길이/로컬 ID 검사.
- 65,536개 색상 round-trip. 10,000개 에셋 색인에서 100,000회 조회는 이 PC의 오프라인 테스트에서 약 100~110ms. 엔진·텍스처 로드가 없는 순수 조회 측정으로 인게임 성능 보장은 아닙니다.
- 실제 저장 함수 88개 범위/성별/기능 조합, 원본 백업 바이트 동일성, 기존 백업 유지, 읽기 잠금으로 백업 실패, 파일 교체 잠금/임시 파일 생성 실패 시 원본 보존.
- 주석/예시/사용자 메모 유지, 활성 규칙 제거 시 주석 유지, 25회 반복 저장 바이트 동일성.
- 동봉 템플릿의 비활성 예시 19개 파싱·모든 범위 포함·문서 필드 설명, 완성 설정 2개 규칙, 첫 예시 활성화 시 정확히 한 규칙만 생성.
- 바닐라 이름 39개와 런타임 별칭 테이블의 레코드 종류/로컬 ID를 두부·Steam의 Skyrim.esm에 읽기 전용으로 대조.
- 기존 선택적 ID 도구 회귀 검사. 일반 이름 지정에 이 도구가 필요하다는 안내는 제거했습니다.
- 한글 HTML의 밝음/어두움 대비 68개 조합(4.5:1 이상) 검사. 색상 CSS는 유지했습니다.

## 범위와 한계

실제 Skyrim은 실행하지 않았으며 설치 모드·MO2·세이브·사용자 규칙을 수정하지 않았습니다. 실제 엔진/모드팩의 모든 이름 제공 여부나 전체 메모리 누수를 증명하는 검사는 아닙니다. 기존 자동 배포의 비UBE/성별/바디타입/후타 등록 제한을 우회하지 않습니다. 플레이어 틴트마스크는 NPC 배포 채널이 없습니다.

schema 8은 이번 새 DLL과 함께 배포해야 하며 이전 schema 7 DLL에 JSON만 교체하면 안 됩니다. 배포 스크립트는 커밋된 소스 리비전과 파일별 SHA-256을 대조해 릴리즈·소스 ZIP을 생성하고, 릴리즈의 빈 schema 8 시작 파일 및 PDB 제외를 확인합니다. 실제 게임/MO2 반영과 인게임 검증은 별도입니다.
