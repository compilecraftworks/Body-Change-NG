Body Change NG 1.1.4 — 2026년 9월 6일

1.1.3의 모든 변경 사항을 포함합니다.

- 구형 v0/v1 Papyrus 스킨 변경이 대기 중일 때 바디 프리셋을 빠르게 연속 선택하면 체형이 누적되던 문제를 수정했습니다. 오래된 UI 작업을 폐기하고 마지막 바디를 한 번 적용한 뒤 선택한 바디스킨·후타나리 스킨을 한 번만 다시 적용하며 자동 액터 작업은 유지합니다.
- NPC의 바디·의상·3D 갱신 직후 바디스킨이 잠깐 보였다가 원래 스킨으로 되돌아가던 문제를 수정했습니다.
- 자동 스킨 적용은 액터의 바디·의상 재구성이 안정될 때까지 기다린 뒤 최종 Biped 복제본을 한 번 다시 칠합니다.
- NPC에게 직접 고른 바디스킨과 기본 스킨은 즉시 수동 선택으로 잠겨 자동 배포가 덮어쓰지 않습니다.
- 몸·손·발·얼굴·생식기·항문 텍스처 경로를 서로 분리하며, 없는 파일은 다른 부위에서 가져오지 않고 액터의 기존 채널을 유지합니다.
- 숨김 장비나 다중 슬롯 NIF 때문에 손·발 지오메트리가 예상과 다른 Biped 항목에 연결된 경우도 수정했습니다. 교차 슬롯 탐색은 정확한 손·발 근거가 있을 때만 허용하며 몸·장갑·신발·생식기 지오메트리는 제외합니다.
- RaceMenu 호출이 접수됐다는 이유만으로 스킨 적용을 성공 처리하지 않습니다. 해당 액터의 최종 몸·손·발·얼굴·해당 해부학 부위를 한 번 확인하고, 불일치하면 정확 경로로 최대 한 번만 복구합니다. 그래도 불일치하면 원하는 스킨을 보류 상태로 남겨 다음 액터·장비 갱신 때 다시 적용합니다.
- 이미 사망한 상태로 로드된 NPC도 바디·스킨 배포 규칙을 적용받아 Zeroed Sliders에 남지 않습니다.
- NPC 배포창을 X·Escape·메인 창 닫기로 종료해도 편집 내용이 다음 실행용 초안으로 자동 저장됩니다.
- 같은 세션에서 배포창을 다시 열 때 초안을 유지하고 세이브 로드 경계에서는 지워 다른 세이브로 오래된 규칙이 새지 않게 했습니다.
- 바디프리셋·바디스킨 후보 목록에 현지화된 전체 선택과 전체 해제 기능을 추가했습니다.
- 현재 세션 규칙과 다음 실행용 저장 경계를 유지합니다. 저장한 편집값은 저장 값 불러오기 또는 로드된 NPC 즉시 배포를 눌러야 현재 세션에서 활성화됩니다.
- 프레임마다 JSON을 쓰거나 폴더를 다시 검색하거나 NPC를 계속 감시하는 처리는 추가하지 않았습니다.
- 릴리즈 빌드와 자동 회귀 테스트 12개를 모두 통과했습니다.
- 실제 MO2 BodySkin 회귀 검사는 종족·노인·SOS·해부학 하위 폴더까지 전체 정규화 경로를 재귀적으로 확인합니다. 다른 팩의 이름이 같은 DDS 때문에 누락 경로가 통과하는 경우도 막았습니다.
