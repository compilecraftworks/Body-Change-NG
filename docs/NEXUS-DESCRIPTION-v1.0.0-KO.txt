[center][size=6][b]Body Changer NG[/b][/size]
바디 · 스킨 · 플레이어 틴트를 하나의 인게임 UI에서 변경하고 NPC에게 조건 배포하는 네이티브 SKSE 모드[/center]

[size=5][b]소개[/b][/size]

Body Changer NG는 BodySlide 바디 모프, 액터별 스킨 텍스처, 플레이어 RaceMenu 틴트 레이어를 한 화면에서 관리합니다. 플레이어와 현재 로드된 NPC를 직접 선택할 수 있고, NPC 배포 조건·세이브별 결과 저장·RaceMenu 종료 후 복원·OBody NG 규칙 호환까지 하나의 구조로 제공합니다.

실행 중 바디 메쉬를 교체하거나 NIF, Skin Armor, ArmorAddon, 장비 슬롯, OBody 원본 JSON을 수정하지 않습니다.

[size=5][b]주요 기능[/b][/size]

[b]바디[/b]
[list]
[*]플레이어 또는 현재 로드된 NPC에게 BodySlide 프리셋 즉시 적용
[*]액터 체중에 맞춰 Low/High Weight 값을 보간
[*]액터 바디 계열을 보수적으로 감지해 메인 바디 목록만 필터링
[*]불확실하거나 여러 계열에 해당하는 프리셋은 안전하게 함께 표시
[*]NPC 배포 풀에는 자동 바디 계열 필터를 적용하지 않음
[/list]

[b]스킨[/b]
[list]
[*]플레이어와 NPC별로 서로 다른 스킨팩 적용
[*]바디·손·발·얼굴·뱀파이어 얼굴 지원
[*]Diffuse, Normal, Subsurface, Specular, FaceGen Detail 텍스처 지원
[*]RaceMenu/NiOverride 영구 키를 사용하며 다른 모드의 키는 삭제하지 않음
[/list]

[b]플레이어 틴트[/b]
[list]
[*]여러 틴트팩 설치 및 선택
[*]플레이어 종족과 현재 레이어에 맞는 DDS 자동 선택
[*]레이어별 색상·강도 상세 조절
[*]Body Changer NG가 처음 변경하기 직전의 RaceMenu 원본 값으로 개별 복원
[*]RaceMenu 종료 후 선택 팩·상세 값·복원 레이어 재적용
[/list]

[b]NPC 조건 배포[/b]
[list]
[*]위에서부터 평가하며 처음 일치한 규칙 사용
[*]바디와 스킨을 각각 배포 또는 배포 제외로 설정
[*]전체 NPC, 커스텀 팔로워, 노인, NPC Base FormID, 이름, 팩션, 플러그인, 종족 조건
[*]한 개 선택 시 고정, 여러 개 선택 시 NPC별 안정적인 랜덤 결과
[*]규칙은 BodyChangerNGdistribution.json, 적용된 액터 결과는 SKSE 코세이브에 저장
[*]로드 순서 변경 시 액터 참조 재해석, 변경 없는 NPC의 불필요한 재배포 방지
[/list]

[b]의상 보정·랜덤화[/b]
[list]
[*]의상 착용 시 가슴 보정 및 별도 유두 보정 옵션
[*]유두·생식기 형태의 안정적인 랜덤화 옵션
[*]OBody NG의 제외 의상·강제 보정·의상별 프리셋 규칙 등록
[*]OBody JSON은 버튼을 눌렀을 때만 읽으며 원본 파일은 수정하지 않음
[/list]

[b]UI·입력·카메라[/b]
[list]
[*]한국어·영어·중국어 UI
[*]마우스, 방향키/WASD, 게임패드 D-pad 탐색
[*]한글 IME, Backspace, 검색, 탭별 즐겨찾기, 크기 조절 가능한 드롭다운·배포창
[*]1080p부터 4K까지 동일 비율 스케일링
[*]좌우 대칭 캐릭터 배치와 플레이어 틴트 확대
[*]일시정지 중 우클릭은 카메라만 회전하여 FSMP 늘어짐 방지
[*]SmoothCam 선택 호환
[*]새 설치 기본값은 게임 일시정지 해제·캐릭터 왼쪽 배치이며 기존 저장 설정은 유지
[/list]

[size=5][b]필수 모드[/b][/size]
[list]
[*]Skyrim SE 1.5.97 또는 검증된 AE 1.6.x 런타임(1.6.1179까지)
[*]게임 버전에 맞는 SKSE64
[*]Address Library for SKSE Plugins
[*]RaceMenu BodyMorph/NiOverride
[*]Build Morphs를 켜고 준비한 BodySlide 프리셋
[*]바디·의상 변화가 보이기 위한 호환 TRI 파일
[/list]

v1.0.0은 Skyrim VR 전용 렌더러/입력 레이아웃이 아직 검증되지 않아 VR에서 UI 훅을 활성화하지 않습니다.

[size=5][b]설치[/b][/size]
[list=1]
[*]메인 파일을 MO2로 설치합니다.
[*]폴더 구조를 유지한 채 모드를 활성화합니다.
[*]BodySlide XML, 스킨팩, 틴트팩을 동봉된 폴더 또는 같은 경로의 별도 MO2 모드에 넣습니다.
[*]SKSE로 게임을 실행하고 F7을 누릅니다.
[/list]

개인 프리셋·스킨·틴트는 메인 모드와 별도 MO2 모드로 관리하면 업데이트할 때 안전합니다. 각 에셋 폴더에는 설치 안내 README가 들어 있으며, 기본 배포 JSON에는 편집 가능한 샘플 제외 조건 8개가 포함됩니다.

[size=5][b]업데이트[/b][/size]

비공개 0.2.x 테스트 버전 사용자는 v1.0.0을 기존 메인 모드 위에 설치할 수 있습니다. 최종 0.2.x의 schema-3 배포 JSON은 그대로 호환됩니다.
