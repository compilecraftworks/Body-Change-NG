Body Change NG 1.1.2 — 2026-09-05

- 네이티브 UI 전체의 창·패널·팝업·제목 표시줄·평상시 컨트롤·입력칸·카드·표·스크롤바·크기 조절 손잡이·탐색 영역을 검정·차콜·회색 바탕으로 통일했습니다.
- 선택·마우스 오버·눌림·경고·성공·진행 상태·즐겨찾기·비호환 표시·실제 틴트 미리보기의 기존 기능적 강조색은 유지했습니다.
- 주변 액터 목록 갱신 버튼을 한국어 `액터 새로고침`, 영어 `Refresh actors`, 중국어 `刷新角色`로 줄였으며 실제 동작은 바꾸지 않았습니다.
- 의상 착용 시 가슴·유두 보정은 확인된 CBBE 3BA 액터에만 적용하며, UBE와 불확실한 여성 계열에는 호환되지 않는 해부학 슬라이더를 기록하지 않습니다.
- 유두·생식기 형태 무작위화를 CBBE 3BA NPC 전용으로 제한하고 UI 명칭을 `NPC 유두 형태 무작위화`, `NPC 생식기 형태 무작위화`로 변경했습니다. 영어·중국어 명칭도 함께 반영했습니다.
- UBE 선택 안내와 옵션 툴팁을 추가했습니다. UBE 플레이어·CBBE NPC 혼합 환경에서 CBBE NPC용 전역 설정은 계속 사용할 수 있습니다.
- 바디프리셋·바디스킨·틴트마스크·배포·카메라·입력·JSON·코세이브 기능은 유지하며, UBE 미지원 해부학 경로는 오히려 작업량을 줄였습니다.
- Release 빌드와 회귀 테스트 실행 파일 12종을 모두 통과했습니다.
