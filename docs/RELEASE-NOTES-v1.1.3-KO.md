# Body Change NG v1.1.3

CBBE 3BA·BHUNP·바닐라 BodySkin의 손·발 분리 적용 수정 — 2026-09-06.

### 수정 내용

- RaceMenu의 단일 스킨 슬롯 적용이 같은 Skin Armor에 연결된 모든 ArmorAddon을 순회해, 적용 순서의 마지막 발 텍스처가 손까지 다시 덮던 원인을 수정했습니다.
- 일반 계열의 몸·손·발은 각 부위의 정확한 ArmorAddon과 현재 로드된 지오메트리에만 적용합니다. CBBE 계열의 발은 정상 구조대로 몸 아틀라스를 사용하지만 손에는 `femalehands_1` 계열이 유지됩니다.
- SFS 등으로 착용한 신발을 화면에서 숨겨도 실제 발 Biped 슬롯이 점유된 경우, 현재 없는 그 부위에만 1비트 영구 키를 저장합니다. Override v0/v1은 필요한 구형 콜백 뒤 보이는 정확한 각 부위를 복구하고, v2는 화면을 광역 재도색하지 않고 키만 저장합니다.
- 플레이어/NPC 수동 선택, 직접 NPC 지정, 조건 배포와 장비 재구성 복구는 같은 백엔드를 사용하므로 모두 수정됩니다.
- 기존 세이브의 완료 기록은 그대로 신뢰하지 않고 새 세션에서 실제 결과를 한 번 확인합니다. 몸·손·발 중 하나라도 선택 스킨과 다르면 다시 적용하고, 이미 정상이면 건너뜁니다.
- UBE는 몸·손·발이 같은 Body 아틀라스를 사용하는 구조이므로 기존 UBE 전용 경로를 유지합니다.
- RaceMenu Override 호환 경로는 구형 SE v0, UBE AE 역포트 v0, 정식 v1, 정식 v2로 명시적으로 분리합니다. 앞의 세 경로는 안전한 Papyrus 문자열 인터페이스를 사용하고 정식 v2만 검증된 native wrapper를 사용합니다. 미확인 미래 ABI는 실패 폐쇄합니다.

### 성능과 호환성

- 새 파일 검색, 타이머 또는 전체 NPC 반복 순회를 추가하지 않았습니다. 누락 부위 보완은 요청된 스킨 적용 중에만 실행하고 노드 재구성은 최대 한 번으로 합치며, 일반적인 정확 부위 적용은 더 짧은 경로를 유지합니다.
- 기존 배포 규칙, 설정, `BodyChangeNGdistribution.json`, 코세이브, 부분 스킨팩, 기본 스킨 복원과 UBE 적용 경로를 유지합니다. 새 세이브는 필요하지 않습니다.
