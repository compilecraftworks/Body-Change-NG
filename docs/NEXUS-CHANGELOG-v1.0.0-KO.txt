[b]Body Changer NG v1.0.0 — 첫 정식 공개 버전[/b]

[list]
[*]BodySlide 바디 모프, 액터별 스킨 텍스처, 플레이어 RaceMenu 틴트를 하나의 인게임 UI에 통합했습니다.
[*]바디와 스킨을 독립적으로 배포하거나 제외할 수 있는 위→아래 첫 일치 NPC 배포 규칙을 추가했습니다.
[*]배포 규칙은 BodyChangerNGdistribution.json에, 평가된 액터 결과는 SKSE 코세이브에 저장해 세이브 로드 때 불필요한 재배포를 줄였습니다.
[*]커스텀 팔로워·노인 바디 제외와 아르고니안·카짓 스킨 제외를 남녀별 기본 샘플 8개로 제공합니다.
[*]OBody NG 배포 규칙과 의상 보정 제외·강제·의상별 프리셋을 사용자가 버튼을 눌렀을 때만 가져오도록 했습니다.
[*]의상 착용 시 가슴/유두 보정과 안정적인 유두/생식기 형태 랜덤화를 추가했습니다.
[*]RaceMenu 종료 뒤 바디·스킨·틴트 상태를 안전하게 재적용하고, 다른 모드가 만든 NiOverride 키는 삭제하지 않습니다.
[*]한글 IME, Backspace, 검색, 즐겨찾기, 키보드·게임패드 탐색, 가변 드롭다운/배포창을 지원합니다.
[*]카메라 좌우 배치를 대칭화하고 메뉴 종료 시 원래 대상·방향·FOV·투영·현재/목표 줌을 복원합니다.
[*]새 설치에서는 게임 일시정지를 해제하고 캐릭터를 왼쪽에 둔 채 메인 창을 화면 중앙선부터 오른쪽으로 배치하며, 기존 저장 설정은 유지합니다.
[*]일시정지 중 우클릭은 액터 루트 대신 카메라만 회전해 FSMP 늘어짐을 방지합니다.
[*]NPC 배포창 하단 버튼 누락, 드롭다운 선택값 공란, 입력 지연/삭제, 틴트 복원 색상 칩 등 공개 전 UI 회귀를 수정했습니다.
[*]SE 1.5.97과 검증된 AE 1.6.x 런타임(1.6.1179까지)을 지원하며, 8개 회귀 테스트를 통과했습니다.
[/list]

자세한 개발 이력은 동봉된 CHANGELOG와 GitHub의 업데이트 히스토리를 참고해 주세요.
