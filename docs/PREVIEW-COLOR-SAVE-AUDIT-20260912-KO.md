# v1.2.0 미리보기 색상·저장·입력·문서 최종 점검

2026-09-12. 이 문서는 이번 추가 수정과 검증 범위의 기록이며 인게임 검증 완료 선언이 아니다.

## 미리보기와 색상

- 오버레이 색상 초안은 액터·부위·항목 ID별 RGBA 값만 보관한다. 임시 액터/재질/텍스처 포인터를 소유하지 않는다.
- 틴트 색상 초안은 팩·레이어별로 유지한다. 메인 창의 항목/탭 전환에서는 유지하고 창 종료·세이브 로드 시작·해당 액터 초기화에서는 정리한다.
- 여러 오버레이 후보를 배포용으로 체크하면 후보 ID별 RGBA를 규칙 초안에 복사한다. schema 7의 선택적 `overlayColors` 필드이며, 없는 옛 규칙은 기존 흰색 기본값으로 읽는다. 자동 배포는 부위별 후보 하나를 고르는 기존 정책을 유지한다.
- 틴트 적용·재적용·복원은 레이어마다 합성 갱신하지 않고 하나의 팩 작업으로 모아 갱신한다. 대체된 단일 레이어 큐 경로는 제거했다.
- 확정 틴트 선택과 렌더 작업을 분리했다. B를 확정한 직후 C 미리보기가 B의 렌더 작업을 대체해도 저장되는 선택은 B다.

## 저장 위치와 검증

| 상태 | 저장 위치 | 확인한 내용 |
|---|---|---|
| 액터 바디·스킨·후타스킨 및 기본값 의도 | `.skse`의 ASTR | 수동/자동 우선순위, 선택 ID, 기본값, 로드 시 FormID 복원 경로 |
| 확정 오버레이 스택 | ASTR | 부위·항목·슬롯·RGBA, 과거 레코드 읽기, 미리보기 완료가 확정 레코드를 대체하지 않는 경로 |
| 얼굴 원본 복원 정보 | FCNI | 기록/읽기 및 잘린 데이터 거부 테스트 |
| 플레이어 틴트 선택·레이어·원본 | TINT v2 | 15개 레이어, 투명도 0, 복원 상태, 원본 DDS/RGB/alpha 왕복, v1 선택 읽기 |
| NPC 배포 조건·후보별 오버레이 색 | `BodyChangeNGdistribution.json` | ID별 색 보존, 불량 색 값만 무시, 명시 저장 후 활성화 |
| UI·단축키·즐겨찾기·의상 보정 설정 | `BodyChangeNG/settings.json` | 기존 설정 경로 유지 |
| 미확정 색상 초안 | UI 세션 메모리 | 항목 재선택 시 유지, 창 종료/로드 시 폐기 |

기존 공용 settings.json의 플레이어 틴트 원본 백업 사용은 제거했다. 어느 캐릭터에서 캡처했는지 알 수 없는 공용 값을 다른 세이브의 원본으로 사용하지 않는다. 새 원본 백업은 TINT v2에 세이브별로 저장한다.

옛 TINT v1에는 세이브별 원본 DDS/RGBA가 없으므로, 없는 과거 원본 정보를 정확하게 복구할 수는 없다. 기존 선택 데이터는 읽는다. 다른 모드가 BCNG 창이 열린 상태에서 강제 저장하는 경우의 RaceMenu 자체 직렬화와 화면 상태까지 통합 검증한 것은 아니다.

## 키보드·게임패드

- `ControlMap::GetMappedKey("Activate", device, kGameplay)`로 확정 입력을 읽는다.
- `ControlMap::GetMappedKey("Cancel", device, kMenuMode)`로 닫기 입력을 읽는다.
- 키보드와 게임패드를 각각 조회하며 고정 E/Space/게임패드 A·B 목록 확정/닫기를 제거했다. 키보드 Enter와 Esc 보조 입력은 유지한다.
- 게임 입력 디스패처 앞에서 해당 입력을 소비한다. 누른 입력의 소유권은 창이 닫히거나 키 매핑이 바뀌어도 해제 시점까지 유지한다. 창 열기 전부터 눌린 버튼의 해제는 원래 입력 수신자에게 돌려준다.
- 실제 새 누름에서 한 번만 실행한다. 누르고 있기, 포커스 복귀 후 남은 held 이벤트, 텍스트 입력 중 Activate가 목록 확정을 반복하지 않도록 했다.
- Cancel은 팝업부터 닫고 본창 종료 시 기존 미리보기 취소 경로를 사용한다. 게임의 실제 컨트롤러/입력 리매퍼 조합 테스트는 아직 하지 않았다.

- 기존 핀을 유지한 SE/AE 전용 Release 빌드 통과.
- 자동 테스트 실행 파일 21개 전부 통과.
- 색상 캐시 동일 항목 10,000회 갱신, 키/버튼 10,000회 누름·해제, 액터/부위/항목 분리, 세이브 교체 및 초기화 검사.
- 실제 생산 코드의 틴트 직렬화 왕복 및 모든 바이트 길이에서 잘린 레코드 거부 검사.
- 영문 설명: BBCode 태그 균형, 제목 색상 24행, 주 섹션 구분선 9개, 코드 블록 전체 경로 불변 확인.
- 영문 변경 내역: 동일 색상 체계와 섹션 구분선 7개 확인.
- 한글 설명/변경 내역: HTML 태그 균형, 중복 ID 및 목차 링크, h1/h2/h3·슬로건 포인트 색상 확인.
- 영문·한글 소개글에서 고정 E/Space/게임패드 A 안내 제거, Activate/Cancel 연동, 간단한 배포 저장 안내, OBody ORefit JSON 명칭·추천 링크 반영.
- Nexus 게시 또는 Nexus 렌더러 실화면 검증은 하지 않았다. 게임 내 반복 저장/재로드, 장시간 GPU/힙 누수, 전체 런타임/RaceMenu 조합 검증을 대체하는 테스트는 아니다.
