Body Change NG v1.2.8

v1.2.7 대비 변경 사항

  • 모드 설정에 '모드 삭제 준비'를 추가했습니다. BCNG 소유 외형을 초기화하고 자동 배포·보정을 중단하며, 정리가 확인됐는지 표시합니다. 배포 규칙과 다른 모드의 모프는 보존합니다. 먼저 세이브를 백업하고, 완료 안내 후 새 슬롯에 저장 → 게임 완전 종료 → 모드 삭제 순서로 진행하세요. 미완료 상태에서는 삭제하지 마세요.
  • 기본값 복원과 세션 초기화 시 액터 포인터뿐 아니라 보관 중인 내부 스킨의 DDS 경로도 원복합니다. 애드온 제공자가 보관한 스킨 조합에 이전 BCNG 경로가 남는 문제를 보완하며 제공자의 원본 폼은 수정하지 않습니다.
  • 새 텍스처 적용 전에 캐시 경로를 재확인하고, 삭제됐더라도 원본이 있으면 다시 생성합니다. 매 프레임 렌더링이나 성기 텍스처 처리에는 파일 검사를 추가하지 않았습니다.
  • 모델의 대체 텍스처 배열 할당·해제를 엔진의 개수 헤더 규약에 맞췄습니다. 교체 실패 시 기존 배열을 유지하고 공개 전 텍스처의 생성 참조를 정리합니다.
  • 몸·원거리 스킨 생성 실패 시 검증된 비공개 복제물을 정리합니다. 내부 텍스처 복원이 실패하면 복원 정보를 유지합니다. 다른 모드가 아직 참조할 수 있는 완성된 그래프는 강제로 해제하지 않습니다.
  • VM이 응답 없이 콜백을 버리거나 응답 전달 작업이 폐기됐을 때 얼굴 작업을 실패·복원 경로로 정리합니다. 롤백·요청 세대·세션 검사를 유지하고 VM이 보관 중인 콜백을 임의로 시간 초과 처리하지 않습니다.
  • 같은 바디 베이스를 공유하는 NPC들을 초기화할 때 각 액터의 얼굴을 개별 복원하고 몸 갱신은 중복하지 않습니다. 이후 새 스킨을 선택하면 이전 기본값 요청은 무효화합니다.
  • NPC의 3D가 언로드된 뒤에도 취소된 바디 미리보기 키를 정리합니다. 현재 미리보기·확정 모프·다른 모드 키는 보존하며 NPC를 강제로 로드하지 않습니다.
  • 바디스킨·후타스킨·틴트 목록의 불변 카탈로그, 텍스처 수, 틴트팩 묶음을 재사용합니다. 화면 밖 행은 생략하되 키보드 포커스와 NPC 배포 체크박스 동작은 유지합니다.
  • 액터 선택 기록을 기존 형식의 여러 레코드에 나눠 저장해 16,384명 초과 시 잘라내지 않습니다. 빈 배포 기록은 만들지 않고 언로드 시 일시적 의상 보정 캐시만 정리합니다.
  • 오버레이 색상 팝업과 삭제 준비 확인창의 Cancel/Esc 입력이 부모 창을 먼저 닫지 않도록 수정했습니다. 삭제 준비 확인창도 다른 팝업처럼 위치를 기억합니다.
  • 기존 Skyrim SE/AE 12개 지원 버전과 RaceMenu 인터페이스 대응을 유지합니다. Skyrim 1.7.x·VR·RSV·Selector 호환은 추가하지 않았습니다.
  • 변경점뿐 아니라 기존 기능군도 검증했습니다. Release 빌드, 회귀 실행 파일 31개, 보조 검사 19개, 12개 런타임의 메타데이터 주소 검사와 오프라인 메모리·목록 성능 검사를 통과했습니다. 배포 파일은 조건·성별·기능 88개 조합, 후보별 색상, 파일 교체 실패·재시도를 검사했습니다. 새 인게임 테스트는 하지 않았으며 TNG 반보라색 제보 재현이나 게임 전체 누수 없음까지 확인한 것은 아닙니다.
