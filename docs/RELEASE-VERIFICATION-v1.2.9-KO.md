# Body Change NG 1.2.9 검증 기록

검사일: 2026-09-19. 1.2.8의 [상세 기능 점검](DETAILED-FUNCTIONAL-AUDIT-v1.2.8-20260919-KO.md)에서 확인한 세 복원 경로만 수정했습니다. 게임 실행·메모리 접근·세이브 조작은 하지 않았습니다.

## 수정 범위

1. 스킨 취소에 `restore` 모드를 사용합니다. 새 미로드 선택은 기존처럼 선택 의도만 수락하지만, 이미 적용된 미리보기 취소는 native 복원까지 전달합니다. 취소 작업은 액터 언로드만으로 사라지지 않으며, 세션 및 베이스별 요청 세대가 새 선택을 보호합니다. 얼굴 요청을 버린 언로드 경계에서는 기존 확정 상태를 무효화해 재등장 시 확인하게 합니다. 같은 바디는 기존 재사용 경로로 처리하며 얼굴 확인을 위해 몸을 다시 만들지 않습니다.
2. 오버레이 언로드 정리는 확정 액터 기록 유무가 아니라 캡처한 미리보기 슬롯으로 처리합니다. 재등장 후 새 미리보기나 확정 슬롯은 제거하지 않고, 같은 텍스처의 확정 색상은 현재 값으로 복원합니다. 실제 슬롯 삭제·색상 변경은 기존 소유권 검사 함수를 사용합니다.
3. Default 복원의 내부 바디 결과를 얼굴 결과와 함께 판정합니다. 몸 복원 실패 시 정상 스냅샷을 만들지 않고 성공으로 기록하지 않습니다. 얼굴 실패 후 기본값으로 되돌리는 보조 복구도 실제 반환값을 따릅니다.

일반 적용에 새 호환성 제한을 추가하지 않았습니다. 새 영구 맵/캐시·상시 스캔·엔진 폼 파괴·새로운 메모리 해제 경로는 없습니다. 의존성 및 런타임/ABI 어댑터, ASTR/얼굴/배포 저장 형식도 변경하지 않았습니다.

## 실행 검사

- 고정 xmake 3.1.0 `build -a`: Release DLL과 테스트 빌드 성공.
- `build/v1.2.9/tests/*Tests.exe`: **32개 통과**. 1.2.8의 기존 31개와 새 PreviewRestoreTests를 포함합니다.
- 실제 제품 함수를 추출하는 PreviewRestoreTests: 미로드 Default/사용자 스킨 취소, 삭제 준비 및 일반 미로드 선택 대조군, 몸/얼굴 각각 성공·실패, 재시도, 이전 세대 무효화, 공유 베이스 얼굴별 정리, 확정 기록 없는 단일/배치 오버레이 언로드, 새 미리보기·확정 색상·다른 텍스처 보존.
- 오버레이 언로드 **10,000회** 후 임시 노드·미리보기 맵·transient 액터 기록·완료 큐 작업 0. 엔진 경계는 가짜 구현입니다.
- FrameTaskQueueTests: 복원 작업의 액터 취소 생존, 새 선택 보호, 세션 초기화 및 **10,000회** 완료 후 작업 잔류 없음. 기존 상호 배제·합치기·공정성 검사는 유지합니다.
- 기존 바디/UBE·스킨/후타·틴트 카탈로그·오버레이·NPC 배포/조건 저장·입력/팝업·직렬화·SFS/보정·삭제 준비·런타임 검사도 재실행했습니다. 기능별 상세 범위는 [이전 전체 검증표](RELEASE-VERIFICATION-v1.2.8-KO.md)를 참조하세요.
- `tools/test-addon-audits.py`: **19개 통과**.
- 배포 메타데이터 Address Library: 기존 **12개 런타임 × 11개 주소 통과**.
- 기존 오프라인 실패 할당 검사: 6그룹 × 100회, 총 **2,977,400회** 할당, 그룹 종료 시 추적된 잔여 바이트/블록 증가 0. 4,096바이트 양성 대조군도 검출했습니다. 이 검사는 가짜 엔진/VM이며 성공 그래프는 검사기가 해제합니다.

## 경계

검사한 취소/실패 경로의 잔류·회귀는 발견되지 않았으나 실제 엔진/GPU의 누수량이나 모든 모드 조합을 검증한 것은 아닙니다. 기존에 외부 제공자가 raw pointer로 참조할 수 있어 보존하는 공개 스킨 그래프의 수명 정책은 변경하지 않았습니다. 제공자/종족 교체 반복에 따른 기존 누적 가능성을 이번 수정으로 해결했다고 주장하지 않습니다. 인게임 텍스처·얼굴 연결·SOS/TNG 크기 변경은 별도 검증 범위입니다.

## 배포 구성

`scripts/Package-Release.ps1`로 검토한 커밋을 기준으로 `release/` 루트에 배포용·소스 ZIP을 생성합니다. 배포용은 DLL·빈 배포 규칙·세 에셋 폴더 안내·두 라이선스 문서의 7개 파일이며 PDB와 진단 파일은 제외합니다. 소스 ZIP은 테스트·문서·고정 의존성의 빌드 필수 파일과 커밋 정보를 포함합니다. 압축 내부 파일은 원본 SHA-256과 대조합니다. MO2 교체는 이번 배포 작업에 포함하지 않습니다.
