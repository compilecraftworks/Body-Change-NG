# Body Change NG v1.3.4

## English

- Align preset XML/weight calculations, including omitted endpoints, negative/over-100 values and UNP reverse sliders.
- Add separate UBE/Necoco breast and nipple outfit correction. Keep body-family separation, SFS visible-outfit handling and shared ORefit exclusions.
- Add UBE/Necoco female genital randomization with correlated Innie/Average/Outie recipes (20%/60%/20%), leaving AnusSpread unchanged. Necoco genital extras require matching loaded TRI morphs.
- Add UBE/Necoco nipple randomization with the original independent probability branches mapped to UBE-specific sliders/ranges. Existing 3BA/BHUNP numerical recipes are unchanged.
- Include female players and NPCs in both randomization options on body-preset confirmation. No distribution rule is required; previews do not reroll anatomy.
- Breast correction, nipple correction, female genital randomization and female nipple randomization all default to **OFF**. Explicitly saved settings are preserved.
- Fix case-sensitive skin/futanari/overlay/tint identity and texture-write checks, restore overlay capacity after known SlaveTats blank textures, and clarify NPC distribution mode while restoring UBE preset candidates.

Install **Body Change NG v1.3.4.zip** with your mod manager. The **Source.zip** is for developers. Keep customized distribution rules, settings, asset packs and texture caches when updating. Distribution schema 8 and co-save formats are unchanged. The binary ZIP keeps the asset-folder structure and necessary runtime/tools/guides/licenses; no PDB or full documentation is included.

**Verification:** Release build and all 40 offline regression executables passed, including 51,712 UBE nipple mappings, comparison with the unmodified reference probability code, and 9,696 UBE genital recipes.

## 한국어

- 생략 끝점, 음수·100 초과 값과 UNP 역방향 슬라이더를 포함해 XML·체중 기반 프리셋 계산을 맞췄습니다.
- UBE/Necoco 가슴·유두 의상 보정을 별도 추가했습니다. 바디 계열 구분, SFS 최종 표시 의상 기준과 ORefit 제외 규칙을 유지합니다.
- UBE/Necoco 여성 생식기 랜덤화를 연관된 Innie/Average/Outie 방식(20%/60%/20%)으로 추가했습니다. AnusSpread는 변경하지 않으며 Necoco 추가 항목은 로드된 TRI에 대응 모프가 있어야 합니다.
- UBE/Necoco 유두 랜덤화는 원본의 독립 확률·분기를 UBE 전용 슬라이더·범위로 변환합니다. 기존 3BA/BHUNP 수치는 변경하지 않았습니다.
- 두 랜덤화 모두 바디프리셋 확정 시 여성 플레이어와 NPC에 적용합니다. 배포 규칙은 필요하지 않으며 미리보기에서는 다시 추첨하지 않습니다.
- 가슴 보정·유두 보정·여성 생식기 랜덤화·여성 유두 랜덤화는 모두 **기본값 해제**입니다. 기존에 명시적으로 저장한 설정은 유지합니다.
- 스킨·후타·오버레이·틴트의 대소문자 식별과 텍스처 기록 판정을 수정하고, SlaveTats의 알려진 빈 텍스처 처리 후 슬롯 수를 복원했습니다. NPC 배포 화면을 구분하고 UBE 프리셋 후보를 복원했습니다.

모드 매니저에는 **Body Change NG v1.3.4.zip**을 설치하세요. **Source.zip**은 개발용 소스입니다. 업데이트할 때 사용자 배포 규칙·설정·에셋 팩·텍스처 캐시는 보존하세요. 배포 schema 8과 코세이브 형식은 유지합니다. 배포 ZIP은 에셋 폴더 구조와 필요한 실행 파일·도구·안내·라이선스만 포함하며 PDB와 전체 문서는 제외합니다.

**검증:** Release 빌드와 오프라인 회귀 실행 파일 40개를 모두 통과했습니다. UBE 유두 변환 51,712개, 수정하지 않은 원본 확률 코드와의 비교, 생식기 조합 9,696개를 포함합니다.
