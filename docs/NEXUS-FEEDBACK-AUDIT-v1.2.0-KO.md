# Body Change NG 1.2.0 Nexus 피드백·회귀 점검

점검일: 2026-09-08

## 확인 범위와 한계

- Nexus [Posts](https://www.nexusmods.com/skyrimspecialedition/mods/189962?tab=posts)의 현재 공개 첫 페이지에는 총 댓글 146개와 최신 루트 스레드 10개가 표시됩니다.
- Nexus [Bugs](https://www.nexusmods.com/skyrimspecialedition/mods/189962?tab=bugs)의 현재 공개 인덱스에는 미해결 보고 3개가 표시됩니다.
- 익명 웹 응답의 Posts 2페이지 이후는 `BH`, `page`, `offset`을 바꾸어도 같은 첫 페이지를 반환했고, 댓글 페이지 이동은 로그인 브라우저의 동적 요청에 묶여 있었습니다. 공개 검색 캐시와 과거 인덱스에서 확인할 수 있는 추가 제목은 별도 구분해 반영했습니다. 따라서 접근하지 못한 댓글을 읽었다고 기록하지 않습니다.
- 아래 결론은 현재 공개 본문, 과거 공개 인덱스, 1.1.x 수정 이력, 1.2.0 소스·테스트, 실제 떼껄룩 자산 스캔을 함께 대조한 결과입니다. 크래시 덤프나 재현 세이브가 없는 보고는 정적 검증 완료와 실게임 재현 완료를 구분합니다.

## 이번 점검에서 추가로 수정한 결함

### 빈 배포 풀의 저장 선택 유실

규칙의 바디 또는 스킨 풀이 비어 있거나 해당 범주가 제외되면 UI 설명대로 `변경 없음`이어야 합니다. 기존 내부 호출은 이 결과를 빈 ID로 합쳐 자동으로 저장된 이전 선택을 지웠습니다. 같은 세션에서는 우연히 현재 외형이 남을 수 있지만 다음 로드 복원에는 선택 ID가 없어 배포가 저장되지 않은 것처럼 보일 수 있었습니다.

1.2.0은 자동 결과를 다음 세 상태로 분리합니다.

1. 값 없음: 저장된 선택 유지
2. 자산 ID: 새 바디 또는 스킨 선택
3. 명시적 Default Body: 선택 ID를 비우고 기본 바디 상태 저장

수동 선택은 자동 규칙이 덮지 않습니다. 바디와 스킨 채널은 각각 독립적으로 이 상태를 유지합니다.

### OStim/ODF와 외부 성기 재질 충돌

장비 이벤트는 의상과 무관한 외부 모드 동작에서도 넓게 발생합니다. 남성 SOS/TNG 또는 여성 SOS/ERF/TRX 후타나리 텍스처를 이벤트마다 다시 칠하면 같은 애드온에 붙은 OStim/ODF의 일시 재질·cum 효과를 BCNG가 덮을 수 있었습니다.

이제 외부 성기 어댑터는 성공적으로 칠한 Armor, ArmorAddon, 슬롯, 영구 노드의 안정 서명을 남성/후타나리 채널별로 저장합니다. 장비·셀 이벤트에서는 실제 애드온 정체가 바뀐 경우에만 다시 적용합니다. 애드온이 제거되면 서명을 지워 같은 Form을 다시 장착해도 새 지오메트리에 적용합니다. RaceMenu 종료 복구는 최종 지오메트리 재생성 뒤 실행되므로 의도적으로 무조건 수행합니다. 일반 몸·손·발·얼굴 스킨은 애초에 장비 이벤트를 보지 않습니다.

### 세이브 로드 반복 시 동적 폼 수명

ActorBase와 런타임에 만든 전용 TXST/ARMA/Skin Armor 폼은 세이브별 레퍼런스가 아니라 Skyrim 프로세스 수명의 게임 데이터 폼입니다. 로드마다 그래프를 새로 만들면 해제할 수 없는 폼이 누적됩니다. 1.2.0은 로드 경계에서 BCNG가 여전히 소유한 포인터를 공급자에게 돌리고 선택·소유 마커를 비운 뒤 기존 전용 그래프를 재사용합니다. 프로필 적용 때는 모든 TXST 채널을 기록된 공급자 경로로 먼저 초기화하므로 이전 스킨의 DDS가 다음 스킨의 몸·손·발에 남지 않습니다.

## 자동 검증과 남은 실게임 인수 조건

자동 검증은 Release DLL 빌드, 테스트 실행 파일 14종, 패키지 구조 검사, `git diff --check`, 실제 떼껄룩 BodySkin/Tint/Futanari 카탈로그를 대상으로 합니다. 실제 자산 기대값은 Legacy 7개, UBE 4개, 스킨 매핑 DDS 139개, 무관 DDS 23개, Tint 85개, Futanari 10개입니다. 7개 일반팩은 별도 스킨 메타데이터 없이 모두 Legacy 목록에 남아야 합니다.

2026-09-08의 기존 실게임 로그도 대조했습니다. Skyrim SE 1.5.97에서 RaceMenu BodyMorph v4 연결은 성공했고, 바디 프리셋은 CBBE/3BA 59, UBE 25, HIMBO 42, SAM 1, 미분류 여성 3으로 총 130개가 로드됐습니다. 반면 당시 1.2 중간 DLL은 스킨 11개를 스캔하고도 7개 Legacy 팩을 `diagnostic-only`로 표시해 목록에서 숨겼습니다. 현재 코드로 같은 원본 폴더를 다시 스캔하면 7개 모두 Legacy로 들어옵니다.
