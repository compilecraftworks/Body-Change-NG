# Body Change NG v1.1.0

바디·스킨·NPC 배포 호환성 업데이트 — 2026-09-04.

### 바디 프리셋과 혼합 바디 환경

- 호환 바디 계열의 슬라이더 집합을 기준으로 프리셋의 절대 목표 체형을 적용합니다. XML에서 생략한 슬라이더는 0을 목표로 하며, 미리보기·확정·NPC 반복 배포가 기존 체형 위에 같은 값을 계속 더하지 않도록 했습니다.
- 전체 모프 삭제 대신 BCNG 소유 보정값을 사용합니다. 다른 모드의 모프 키를 삭제하지 않으며 미리보기와 확정·NPC 배포의 소유권을 분리합니다.
- 로드된 스킨·얼굴 근거로 액터별 CBBE 3BA와 UBE를 감지합니다. XML의 Preset set·Group 정보를 우선 분류하고, 불확실하거나 여러 계열에 해당하는 프리셋은 안전한 표시 폴백을 유지합니다.
- 사용자가 선택한 배포 풀은 그대로 보존하고, 실제 바디·스킨 선택 시 액터 성별과 확인된 계열을 검사합니다. 의상 관련 이름이 있다는 이유만으로 바디 목록에서 일괄 제외하지 않습니다.

### 스킨 지원과 부위·채널 연결

- 남성 스킨 경로와 손·발 대상 탐색을 수정했습니다. 첫 번째 장비 슬롯에서 파트를 찾지 못하는 다중 슬롯 스킨 아머도 제한된 보조 탐색으로 처리합니다.
- 미리보기·확정·NPC 배포 모두 부분 스킨팩을 지원합니다. 몸·손·발·얼굴 및 Diffuse·Normal·Subsurface·Specular 중 제공된 부위·채널만 바꾸고, 없는 값은 원본을 유지하며 다른 부위나 채널로 대신 채우지 않습니다.
- UBE 2.0 Body·Head 아틀라스와 아르고니안·카짓 남녀 스킨을 액터별로 구분하며, 해당 몸 아틀라스를 사용하는 꼬리 지오메트리도 처리합니다.
- femaleold와 인간형 종족별 얼굴 노멀은 맞는 액터에게 파일이 있는 채널만 적용합니다. Astrid·Afflicted 전용 텍스처와 BodySkin 안의 틴트마스크 DDS는 바디스킨 적용 대상에서 제외합니다.
- CBBE 3BA femalebody_etc_v2_1은 질·항문 공용 아틀라스에, BHUNP/UNP BakaUNP/VaginalAnalCanal2는 해당 질·항문·내부 지오메트리에 연결하며 일반 바디 텍스처와 분리합니다.
- 스킨팩의 원본 SOS 폴더에서 Smurf Average·VectorPlexus Regular·VectorPlexus Muscular 슬롯 52 텍스처를 지원합니다. 현재 애드온·종족·노인 재질에 맞춰 적용하며 Muscular는 원본 구조에 맞는 Regular 채널 상속을 사용합니다.
- 확인된 UBE·일반 플레이어 틴트팩을 구분하되 계열 판정이 불확실할 때는 안전한 폴백을 유지합니다. 틴트 기능은 플레이어 전용입니다.

### NPC 배포와 성능

- 기존 조건에 키워드·클래스·전투 스타일을 추가했습니다. 팩션 드롭다운은 이름이 없는 레코드도 EditorID·플러그인·로컬 ID로 표시합니다.
- schema 4에서 팩션·종족·키워드·클래스·전투 스타일 대상을 플러그인+로컬 FormID로 저장합니다. 기존 schema 3 규칙도 읽을 수 있으며 저장 시 새 형식으로 전환합니다.
- 기본 제외 샘플 8개를 유지합니다. 커스텀 팔로워·노인 남녀는 바디만, 아르고니안·카짓 남녀는 스킨만 배포 제외입니다.
- 일반 모드와 성능 모드 모두 자동 액터·장비 이벤트를 병합하고 RaceMenu 파티션 갱신을 지연 처리하며 불필요한 의상 모프 재빌드를 건너뜁니다. 성능 모드는 추가 처리 간격을 둡니다.
- 최초 로드된 NPC 처리는 직렬화·RaceMenu·오버레이 로드 콜백이 몰리는 구간에서 두 게임 태스크 뒤로 옮겼습니다. 반복 파일 스캔이나 타이머를 추가하지 않으며 카탈로그 기반 슬라이더 집합은 캐시합니다.

### 마이그레이션·UI·릴리스

- 구형 플러그인 제거 후 BodyChange.esp 얼굴 HeadPart를 참조하는 일반 RaceMenu .jslot 파일을 복구합니다. 같은 위치에 백업을 만들고 사용 가능한 High Poly Head를 우선, 없으면 바닐라 대상을 사용하며 UBE 커스텀 헤드 프리셋은 보존합니다.
- 메인 탭 명칭을 바디프리셋·바디스킨·틴트마스크로 정리하고 한국어·영어 릴리스 문서를 갱신했습니다.
- 기존 설정·코세이브 식별자·소유 키와 BodyChangeNGdistribution.json 파일명을 유지합니다. 1.1.0 버전 변경만으로 이름을 바꾸거나 초기화하지 않습니다.

## 1.0.0에서 업데이트

- Skyrim을 종료한 뒤 DLL을 교체합니다.
- 현재 사용하는 `Data\SKSE\Plugins\BodyChangeNGdistribution.json`과 설정을 백업합니다. MO2 Overwrite·프로필 사본도 확인하고, 새 패키지의 샘플 JSON으로 개인 규칙을 덮어쓰지 마세요.
- BodySkin·TintMask·SliderPresets의 개인 파일은 유지하고, 가능하면 별도 MO2 모드로 관리합니다.
- 기존 schema 3·4 규칙을 읽을 수 있으며 저장 시 schema 4로 기록합니다. 코세이브 식별자와 JSON 파일명은 그대로입니다.
- 파일 추가·변경 후 해당 목록을 새로고침합니다. 변경한 규칙을 로드된 NPC에게 적용하려면 배포창의 즉시 배포 기능을 사용합니다.
