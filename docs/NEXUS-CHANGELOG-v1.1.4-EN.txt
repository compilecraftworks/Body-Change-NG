Body Change NG 1.1.4 — 6 September 2026

Includes all changes from version 1.1.3.

- Fixed body morphs growing cumulatively when Body presets were clicked rapidly while a legacy v0/v1 Papyrus skin change was still pending. Obsolete interactive work is now superseded, the latest body is applied once, and the selected BodySkin/futanari skin is repainted once afterward without dropping automatic actor work.
- Fixed NPC skins that flashed briefly and immediately reverted after body, outfit, or 3D rebuilds.
- Automatic skin application now waits for the actor's body/outfit rebuild to settle, then repaints the final Biped clone once.
- Manual NPC skin and Default Skin selections now lock immediately, so automatic distribution cannot overwrite the user's direct choice.
- Correct body, hands, feet, face, genital, and anal texture routes remain isolated; missing files keep the actor's existing channel instead of borrowing another body part.
- Already-dead loaded NPCs can now receive body and skin distribution rules instead of remaining on Zeroed Sliders.
- NPC Distribution edits are automatically saved as the next-launch draft when the panel is closed with X, Escape, or the main window.
- The same-session draft is preserved while reopening the panel and is cleared at a save-load boundary, preventing stale rules from leaking into another save.
- Added localized Select all and Clear all controls for body-preset and skin candidate pools.
- Preserved the active-session versus next-launch rule boundary: only Load Saved Values or Distribute to Loaded NPCs Immediately activates saved edits in the current session.
- The fixes add no per-frame JSON writes, directory rescans, or continuous NPC polling.
- Release build and all 12 automated regression tests passed.
