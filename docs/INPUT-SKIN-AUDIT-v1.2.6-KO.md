# v1.2.6 입력 회귀·스킨 깜빡임 점검

## 범위와 근거

- 기준: main de9255d(v1.2.5). 제보자의 로그·모드 목록·재현 환경은 확보할 수 없다.
- 클릭 불가는 1.2.5 이후 제보다. 스킨 깜빡임은 1.2.5에서 처음 발생했다고 확인되지 않았다.
- 과거 2026-09-16 로컬 로그는 이번 제보의 증거나 현 버전 검증으로 사용하지 않았다.
- CommonLibSSE-NG 6.7.1, xmake 3.1.0 및 잠긴 의존성은 그대로다. SE/AE 전용이며 1.7.x·VR 지원을 추가하지 않았다.

## 클릭: 확인된 전달 경로 누락

1.2.5는 Scaleform 마우스 전달을 제외하고 Windows 메시지에서 버튼·휠을 큐에 넣었다. 게임 입력 훅은 우클릭만 별도 원자 상태로 전달했다. 따라서 게임 입력은 들어오지만 Windows 클릭 메시지가 전달되지 않는 경우 좌클릭이 UI에 도달하지 않는다. 제보 환경에서 실제 메시지가 유실되는 위치까지 관찰한 것은 아니다.

수정 후에는 기존 게임 입력 훅에서 왼쪽·오른쪽·가운데·추가 버튼과 휠의 엣지를 하나의 제한된 큐에 넣는다. 커서는 계속 Skyrim MenuCursor 기준이다. Windows·Scaleform은 같은 엣지를 중복 주입하지 않는다. 빠른 우클릭의 down/up을 마지막 상태 하나로 덮어쓰던 경로와 불필요한 Win32 마우스 캡처 관리도 제거했다. 기존 게임 입력 차단 정책과 키보드·패드 매핑은 바꾸지 않았다.

기존 테스트는 Windows 메시지가 도착했다고 가정하고 큐를 직접 주입했으므로 이 전달 누락을 잡지 못했다. 이번에는 실제 게임 버튼 ID 진입점으로 Windows 메시지 없이 입력을 재생하고, 프로덕션 입력 훅 연결에 대한 소스 검사도 추가했다.

## 스킨: 확인된 중복 작업과 남은 불확실성

NiNode 갱신 알림은 얼굴 적용 완료 상태를 무효화하고 얼굴 작업을 다시 수행한다. 이전 코드는 실제 얼굴 DDS가 그대로여도 각 채널을 무조건 다시 썼다. 이는 확인된 중복 텍스처 갱신 경로이며, 재질이 갱신되는 순간을 불필요하게 늘린다. 그러나 이것이 제보자의 몸/얼굴 깜빡임의 직접 원인인지는 확인하지 못했다.

즉시 NodeOverride API를 사용하는 경우에 한해 다음 조건을 모두 만족하면 해당 채널 재로딩을 생략한다.

- 원하는 DDS와 현재 속성 경로가 같다.
- 실제 NiSourceTexture의 전체 리소스 경로도 같고 렌더러가 존재한다.
- 저장 적용이라면 저장된 오버라이드도 이미 같은 경로다.
- 별도로 갱신해야 할 다른 1인칭 얼굴 재질이 없다.

다른 팩, 잘못된 실제 텍스처, 렌더러 누락, 저장 오버라이드가 아직 없는 미리보기 확정은 기존 쓰기 경로를 실행한다. 기본값 복원·실패 롤백·이전 머리 정리는 바꾸지 않았다. 비동기 Papyrus 대체 경로도 그대로다. CBBE/UBE에 한정된 변경이 아니다.

새로운 반복 폴링·강제 몸 재생성·원본 NIF 수정·타 모드 오버라이드 삭제는 추가하지 않았다. RSV/Selector 등 다른 외형 제어 모드와의 충돌을 억지로 덮어쓰는 변경도 하지 않았다. 누락 모프 복구나 애드온 재연결이 실제로 재생성 루프를 만든다는 증거는 찾지 못했으므로 추정만으로 해당 기능을 제거하지 않았다.

## 회귀·수명 관리 점검

- Release DLL 빌드 및 자동 테스트 실행 파일 26개 통과.
- 실제 ImGui 입력 재생: 60/15/5 FPS 각각 게임 입력 클릭 20/20회 처리. Windows 좌표 혼합 실패 대조군도 유지.
- 버튼 5개, 드래그, 더블클릭, 휠 방향·릴리스, 짧은 우클릭, 중복·held 입력, 포커스/재열기 정리, 키보드 큐 보존 검사.
- 렌더 지연 중 10,000개 버튼 엣지를 주입하는 큐 상한 및 초기화 검사.
- 얼굴 경로 정규화, 반복 동일 DDS, 다른 팩, 저장 확정, 실제 텍스처 불일치, 렌더러 누락 검사.
- 기존 얼굴 복원·직렬화·채널별 실패 롤백 정책, 비동기 세션/세대 취소, 프리뷰 수명, NPC 배포 상태, 후타 저장, 런타임 경계 테스트 유지.
- 새 장기 보유 액터/geometry/material/texture 포인터 없음. 렌더 리소스는 기존 게임 스레드 작업 안에서만 잠깐 확인한다. 직렬화 형식 변경 없음.

자동 테스트는 게임 엔진·GPU 통합 또는 장시간 실사용 누수 검사가 아니다. 실제 게임에서 클릭·스킨 전환·미리보기 취소를 재현 검증하지 않았으며, 스킨 깜빡임 완전 해결로 표시하지 않는다.
