Body Change NG v1.3.1

- 선택적으로 사용하는 오프라인 캐시 정리 도구를 추가했습니다. Skyrim 종료 후 Tools\BodyChangeNGCache.exe를 직접 실행하고 MO2 Overwrite를 선택하세요. 먼저 변경 없이 검사하며 확인 후 정리합니다.
- 조건에 맞는 동일 DDS 복사본을 하드링크로 합쳐 경로를 유지하면서 저장 공간을 회수합니다. 예전 세이브와 1.2.7 캐시 경로도 유지합니다. 고유 텍스처, 외부 하드링크, 수정 시각이 다른 파일, 읽기 전용·잠긴 파일과 알 수 없는 구조는 보존하며 절약량은 실제 중복 상태에 따라 다릅니다.
- 게임 종료 후 남은 준비/링크 임시 파일 중 게임에 전달되지 않는 것으로 확인된 파일만 제거합니다. 원본 스킨팩·세이브·배포 규칙은 수정하지 않습니다. 모든 세이브 참조를 분석하거나 오래된 DDS를 일괄 삭제하는 기능은 아닙니다.
- 새 런타임 DDS는 임시 경로에서 완성한 뒤 원자적으로 반영합니다. 준비 실패 시 기존 정상 캐시를 유지하고 자신의 임시 파일을 정리하며 읽기 전용 원본 속성은 보존합니다.
- 기존 기능·1.3.0 복원 수정·지원 런타임·의존성을 유지하고 게임 중 캐시 검사를 추가하지 않았습니다. Release 빌드, 오프라인 회귀 실행 파일 35개, 보조 검사 19개 통과. 새 인게임 테스트는 수행하지 않았습니다.
