Body Change NG v1.2.4 — v1.2.3 대비 변경

- SetSlider가 없는 유효한 UBE Zeroed 프리셋을 미리보기·확정·저장된 선택 복원에서 허용합니다.
- 일반 UBE XML 끝값을 실제 Zeroed 빌드 기본값에 대한 차이로 적용합니다. 누락 끝점, 음수·100% 초과 값, 별도 가산 Refit 프리셋과 다른 바디 계열의 기존 계산은 유지합니다.
- 몸 재생성 완료 상태를 직접 확인하여 얼굴 갱신이 NiNode 알림에만 의존하지 않도록 보완했습니다. 실제 준비 상태, 오래된 요청 취소 및 제한된 실패 처리는 유지합니다.
- 몸·손·발의 Skin TXST가 없으면 고정된 UBE 경로 대신 원본 NIF의 실제 피부 재질에서 적용 대상을 만듭니다. 전체 채널 기본값과 노멀맵 방식을 보존하며, 서로 다른 아틀라스는 하나로 강제하지 않고 복제 모델의 형상별 대체 텍스처로 처리합니다. 기존 네이티브 텍스처 제공자는 우선 유지합니다.
- 처음 선택한 팩과 무관하게 재사용 가능한 몸 적용 대상을 준비합니다. 얼굴 전용 팩을 먼저 선택한 뒤 몸 포함 팩으로 바꿀 때 몸 적용 대상이 빠지던 문제를 수정했으며, 얼굴 전용 적용 자체는 몸에 연결하지 않습니다.
- 커스텀 NPC의 바디 계열 판정을 개선했습니다. 실제 피부 근거를 오래된 폼·폴더 이름보다 우선하고, 애드온 정보는 해당 종족에 맞는 몸 부품으로 제한하며, UBE 설치 여부만으로 확인된 일반 계열을 뒤집지 않습니다. 모든 커스텀 NPC를 한 계열로 강제하지 않고 CBBE/UNP 프리셋 누락의 코드상 원인을 수정했습니다.
- 기존 3D 갱신 이벤트에서 해당 액터의 계열 캐시를 무효화하고 일상적인 분류 로그를 줄였습니다. 팩 전환 시 생성된 스킨 그래프를 재사용하며 OBody/OClothe 키 정리, 모프 보존 옵션, 부분 DDS 적용, 미리보기 취소 및 코세이브 형식은 유지합니다.
- 영문·한글 안내를 갱신했습니다. OBody NG, Racial Skin Variance - SPID (RSV), RaceMenu Selector of Skins - Unique Player Character를 동시 외형 제어 비호환 모드로 안내합니다. 버튼을 ORefit 의상 보정 규칙 등록으로 바꾸고 ORefit JSON Master List 링크를 안내합니다.
- 임시 얼굴 미리보기 진단 기록 기능을 정식 소스와 빌드에서 제거했습니다. RSV·Selector 호환 훅이나 충돌을 자동 차단하는 패치는 포함하지 않습니다.
- 검증: 자동 테스트 실행 파일 25개, 액터 계열 근거 조합 4,374건, 실제 설치 UBE OSP 기반 재구성 계산 17,045건. AE 1.6.1179의 몸·얼굴 비대칭을 포함한 제보 환경의 인게임 재현 확인은 아직 남아 있습니다.
