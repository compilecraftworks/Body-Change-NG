# v1.3.8 릴리즈 검증 — 2026-10-24

## 변경 범위

- 플레이어 뱀파이어 로드·늑대인간 스킨 옵션을 각각 추가했다. 기본값은 변신체 고유 스킨이며, 호환되는 휴머노이드 변신 모드는 BCNG 스킨 유지를 선택할 수 있다. 일반 뱀파이어와 NPC 변신 정책은 변경하지 않는다.
- 변신 중 BCNG 소유 스킨과 얼굴 저장값을 해제하되 확정 선택은 보존한다. 변신 상태에서 불러오기와 변신 해제 후 복원을 기존 작업 큐에 연결하고 이전 종족의 대기 작업을 차단한다. 동일 종족의 첫 미리보기는 취소하지 않는다.
- 기존 UBE 배포 설정을 유지하면서 스킨 목록·항목변경 팝업·실제 후보에서 Legacy만 허용하던 조건을 제거했다. 설정한 계열 및 실제 NPC 바디의 알려진 호환성을 함께 확인한다. 혼합 계열 자동 배포나 프리셋 계산 변경은 포함하지 않는다.

## 검사 결과

새 `build/v1.3.8/tests`의 회귀 실행 파일 **51/51 통과**. 이전 버전 바이너리나 별도 조사용 Probe는 집계하지 않았다. 파일 교체·잠금·하드링크 검사는 Windows 경로 길이 제한을 넘지 않는 작업 폴더 내 짧은 임시 경로에서 실행했다.

- 변신: 실제 제품의 판정·전환·복원 함수를 엔진 대역과 함께 검사했다. 두 변신의 독립 옵션, 일반 뱀파이어 제외, 방어구 종족 상속, 변신 상태 불러오기, 지연된 3D 준비, 세션 변경, 기본 스킨 선택, 명시적 기본 스킨, 외부 모드 소유권, 첫 미리보기 보존을 포함한다.
- 반복 전환: 100회 변신·복귀에서 스킨 그래프 재사용을 확인했다. 휴머노이드 변신의 옵션 전환에서도 BCNG가 해제한 임시 값과 외부 모드 변경을 구분한다.
- 비동기 얼굴 처리: 종족 전환 뒤 이전 얼굴 작업은 중단하고, 저장된 BCNG 소유 키의 정리는 크리처의 얼굴 메시 없이도 진행한다.
- UBE 배포: 실제 목록/후보 함수와 스킨 호환 함수로 UBE·3BA·UNP·HIMBO·SAM 설정, 성별·종족, 대소문자, 알려진 비호환 NPC, 알 수 없는 바디를 검사했다. 기존 프리셋 배포의 1,000회 모드 전환 검사도 통과했다.
- 기존 모프 수치·체중 보간·RaceMenu ABI·런타임 레이아웃·입력·휠·미리보기·배포 저장·어린이 제외·스킨 복구·오버레이 회귀 검사도 통과했다.
- 의존성 잠금 파일의 내용은 변경하지 않았다.

## 패키징 검사 규칙

`scripts/Package-Release.ps1`은 깨끗한 커밋에서 배포 ZIP과 소스 ZIP을 만든다. DLL 버전, 배포본 11개 파일, 비활성 schema-8 기본 규칙, 필요한 소스 의존성·라이선스, 모든 ZIP 항목의 SHA-256을 대조한다. 소스 ZIP에 `SOURCE-REVISION.txt`를 포함하고 두 ZIP의 SHA256SUMS를 함께 발행한다.

## 검사 범위

이번 확인은 오프라인 빌드와 코드 회귀 검사다. 게임 내 실제 변신·렌더링을 실행한 결과로 표현하지 않는다. 게임·세이브·MO2 설치본은 이번 릴리즈 작업에서 변경하지 않았다. 한·영 사용자 변경 내역은 [릴리즈 노트](RELEASE-NOTES-v1.3.8.md)에 정리했다.
