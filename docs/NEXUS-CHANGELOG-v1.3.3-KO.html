Body Change NG v1.3.3

게임 밖에서 준비하는 NPC 배포

주석 규칙과 실제 작성 예제

  • Data\SKSE\Plugins\BodyChangeNGdistribution.json에서 // 및 /* ... */ 주석을 지원합니다. 기존 주석 없는 schema 7 파일도 사용할 수 있습니다.
  • 필드 19개·대상 조건 11종을 한영 주석으로 설명합니다. 비활성 예제 19개와 노드 여성에게 바디·스킨을 배포하는 완성 설정을 제공합니다.
  • 기본 게임 조건 값 39개와 게임을 실행하지 않고 커스텀 종족·팩션·키워드·클래스·전투스타일을 찾는 방법을 넣었습니다.
  • 바디·스킨·후타스킨·오버레이 후보를 여러 개 넣는 예제를 추가했습니다. 기능별 후보를 따로 선택하며, 전부 겹쳐 적용하거나 바디·스킨을 짝지어 배포하지 않습니다.
  • 선택적 읽기 전용 PowerShell 도구로 프리셋·등록 오버레이 ID를 확인할 수 있습니다. 별도 한영 안내에서 모드팩 사전 설정, 설치, 플러그인·로컬 ID와 규칙 우선순위를 설명합니다.

업데이트와 저장

  • 기본 템플릿의 활성 규칙은 0개입니다. 업데이트할 때 사용자가 만든 기존 규칙 파일을 보존하세요.
  • 주석 파일은 1.3.3 이상 DLL이 필요합니다. 인게임 규칙 저장 시 주석 없는 JSON으로 다시 쓰므로 편집용 원본은 따로 보관하세요. 다른 JSON 입력에 주석 기능을 추가한 것은 아닙니다.
  • 기존 외형 기능, 배포 판정, 세이브 형식, 지원 게임·RaceMenu 인터페이스와 고정 의존성은 유지합니다. 게임 중 반복 검사나 영구 캐시를 새로 추가하지 않았습니다.

검증

Release 빌드, 오프라인 회귀 실행 파일 35개, 규칙 작성 검사, 배포 저장 88개 조합과 조건 ID 대조를 통과했습니다. 새 인게임 테스트는 수행하지 않았습니다.
