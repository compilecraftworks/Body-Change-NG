Body Change NG v1.3.3

숫자 대신 이름으로 편집하는 NPC 배포 규칙

이름 지정과 이전 설정 마이그레이션

  • NPC 규칙을 사람이 읽고 편집하는 schema 8로 확장했습니다. 내부 ID 대신 BodySlide/BCNG 프리셋 이름, 스킨·후타팩 이름, 등록 오버레이 이름을 입력합니다.
  • 대상 조건 11종을 이름으로 지정합니다. 종족·팩션·키워드·클래스·전투스타일은 EditorID 또는 고유한 게임 표시 이름을 사용하며, 동명 구분용 플러그인과 이름이 없는 레코드용 로컬 16진 ID 표기도 지원합니다.
  • 오버레이 후보 색상은 #RRGGBB / #RRGGBBAA로 입력합니다. 복수 후보는 기능·부위별로 따로 선택하며 기존 액터 호환성·자동 배포 제한은 유지합니다.
  • 비활성 예시 19개, 그대로 복사할 바닐라 대상 이름 39개, 완성 설정과 동명 구분법을 한영 주석 템플릿·별도 가이드에 정리했습니다. 일반적인 이름 편집에는 숫자 ID 도구가 필요하지 않습니다.
  • 기존 schema 3~7은 원본 그대로의 .schemaN.bak 백업을 남긴 뒤 변환합니다. 이미 있는 백업은 덮지 않습니다. 확인된 항목은 이름으로 바꾸고 미확인 옛 ID·못 찾은 새 이름도 보존합니다. 규칙 순서·후보 색상과 기존 옛 규칙 정리 동작을 유지합니다.
  • schema 8의 enabled:false로 개별 규칙을 끌 수 있습니다. 옛 enabled는 무시되던 동작을 유지해 변환합니다. 중복 이름을 임의 선택하지 않으며 필드·범위 오타를 전체 조건으로 확대하지 않습니다.
  • 시작 파일의 활성 규칙은 0개입니다. 인게임 명시 저장은 실제 규칙을 맨 위에 쓰고 기존 주석·예시를 아래에 중복 없이 보존합니다. 사용자 규칙 파일은 유지하세요. 새 형식은 새 DLL이 필요하며 JSON만 교체하는 업데이트가 아닙니다.
  • 에셋 이름 색인은 목록 변경 때 갱신하고 액터 호환성은 후보 묶음당 한 번 검사합니다. 매 프레임 검사·엔진 훅·지원 런타임·co-save 형식은 추가하거나 바꾸지 않았습니다.
  • 한글 소개글·체인지로그 HTML의 브라우저 밝음/어두움 자동 색상을 유지합니다.

검증

검증: Release 빌드와 오프라인 회귀 실행 파일 36개 통과. 실제 이름 변환 함수, schema 3~7 변환, 저장 88개 조합, 색상 65,536개 재변환, 주석 보존 반복 저장을 포함합니다. 바닐라 대상은 두 Skyrim.esm과 대조했습니다. 인게임 테스트는 수행하지 않았습니다.
