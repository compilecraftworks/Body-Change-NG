Body Change NG v1.3.1

캐시 저장 공간 정리

  • 선택적으로 사용하는 오프라인 도구를 추가했습니다. Skyrim 종료 후 Tools\BodyChangeNGCache.exe를 MO2가 아닌 탐색기에서 직접 실행하고 MO2 Overwrite를 선택하세요. 먼저 변경 없이 검사하며 확인 후 정리합니다. 확인 창의 기본 선택은 No입니다.
  • 조건에 맞는 동일 DDS 복사본을 하드링크로 합쳐 모든 경로와 내용을 유지합니다. 예전 세이브와 1.2.7 캐시 경로도 유지합니다. 데이터가 공유되므로 폴더 표시 용량은 그대로일 수 있으며 실제 절약량은 중복 상태에 따라 다릅니다.
  • 고유 텍스처, 외부 하드링크, 수정 시각이 다른 파일, 읽기 전용·잠긴 파일, 링크/정션과 알 수 없는 구조는 보존합니다. 오래됐거나 현재 선택되지 않았다는 이유로 DDS를 삭제하지 않습니다.
  • 게임 종료 후 남은 준비/링크 임시 파일 중 게임에 전달되지 않는 것으로 확인된 파일만 제거합니다. 원본 스킨팩·세이브·배포 규칙은 수정하지 않습니다. 모든 세이브 참조를 분석하는 도구는 아닙니다.

텍스처 준비와 검증

  • 새 DDS는 임시 경로에서 완성한 뒤 원자적으로 반영합니다. 준비 실패 시 기존 정상 캐시를 유지하고 자신의 임시 파일을 정리합니다. 읽기 전용 원본 속성과 기존 텍스처 식별 방식은 보존합니다.
  • 기존 기능·1.3.0 복원 수정·지원 런타임·의존성을 유지하고 게임 중 캐시 검사는 추가하지 않았습니다.
  • Release 빌드, 오프라인 회귀 실행 파일 35개, 보조 검사 19개 통과. 새 인게임 테스트는 수행하지 않았습니다.
