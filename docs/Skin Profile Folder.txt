Each skin has one self-contained folder:

BodySkin\<skin name>\
  Textures\              (copy the skin mod's textures folder here)
  profile.json            (optional)

Without profile.json, Body Change NG automatically detects standard
femalebody/femalehands/femalefeet and malebody/malehands/malefeet texture
names plus their femalehead/malehead face textures. Argonian female/male and
Khajiit female/male folders are also detected separately. Player selection and
NPC distribution rules use the catalog separately and match race, sex, and
body family before applying a skin.

A pack may contain only some parts or channels. Only the supplied body, hands,
feet, or face channels are overridden; missing ones retain the actor's current
textures. A file from one part is never reused for a different part.

Use profile.json only for an explicit custom selection. `Textures\...` paths in
that file are relative to this skin folder. Its optional `race` value is
`humanoid`, `argonian`, or `khajiit`.
