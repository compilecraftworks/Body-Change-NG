Body Change NG 1.2 skin packs do not use profile.json.

Each selectable skin is one self-contained folder:

BodySkin\<skin name>\
  Textures\              (copy the skin mod's original texture tree here)

The top-level folder name is the display name. Its relative folder path and
detected sex form the stable automatic catalog ID. A stale metadata JSON file
is ignored and cannot replace that ID or change any DDS mapping.

Only an explicit Textures\!UBE\Body or Textures\!UBE\Head tree is classified
as UBE. Every other conventional humanoid female or male texture tree is
Legacy. CBBE/3BA versus UNP/BHUNP and vanilla versus HIMBO/SAM are resolved
from the selected actor's runtime BodyFamily only when the skin is applied.
Argonian and Khajiit folders remain separate race-safety boundaries.

Partial packs are valid. Only detected body, hands, feet, face, genital, and
material channels are overridden. Missing files keep the actor's current
texture. DDS files are never guessed or copied across body-part roles.
