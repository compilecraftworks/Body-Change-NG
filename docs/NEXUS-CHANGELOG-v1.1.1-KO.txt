Body Change NG 1.1.1 — 2026-09-05

NPC 배포와 저장 복원

- 세이브를 불러온 뒤 수동 지정하거나 조건 배포한 NPC의 바디·스킨이 실제로 남아 있는지 처음 만났을 때 한 번 확인합니다. 적용값이 없거나 깨졌으면 자동으로 다시 적용하고, 이미 정상이면 중복 작업하지 않습니다.
- 같은 액터에게 겹쳐 들어오는 초기화·셀 부착·의상 변경 작업을 합치고, 이전 세션에서 남은 작업을 로드 시 무효화했습니다.
- 3D가 아직 준비되지 않은 액터는 제한된 횟수만 재시도하며, 적용에 성공한 결과만 완료 상태로 저장합니다.

바디 프리셋과 의상 보정

- RaceMenu의 기존 3BA MORPHS 값이나 반복 배포 위에 프리셋이 계속 더해져 몸이 커지는 문제를 수정했습니다. XML에 없는 호환 슬라이더는 0을 목표로 삼고, 다른 모드의 모프 키는 삭제하지 않은 채 선택 프리셋의 절대 결과에 맞춥니다.
- 미리보기·확정·NPC 배포가 같은 절대 적용 경로를 사용하며, 오래된 미리보기나 자동 배포가 현재 선택을 덮어쓰지 않습니다.
- 바디 재적용 뒤 의상 보정을 다시 계산하고, 실제 전체 모프 결과를 기준으로 가슴·유두 보정을 맞춥니다.
- 액터의 실제 바디 계열을 기준으로 CBBE 3BA와 UBE 2.0의 가슴·유두 보정 및 유두·생식기 랜덤화 슬라이더를 분리했습니다. 다른 계열의 해부학 슬라이더는 섞지 않습니다.

BodySkin 적용

- 여러 부위가 한 Skin Armor에 들어 있는 경우에도 몸·손·발 geometry를 이름과 실제 텍스처 경로로 구분합니다. 몸 텍스처가 손이나 발에 잘못 복제되지 않습니다.
- 불완전한 스킨팩은 들어 있는 부위와 diffuse·normal·subsurface·specular 채널만 교체하고, 없는 부위와 채널은 액터의 현재 텍스처를 유지합니다.
- 의상 착탈이나 사망 NPC의 장비 약탈로 3D가 재구성된 뒤에도 선택한 스킨을 확인하고 필요한 부위만 복구합니다.
- 세이브에 기록된 BCNG 텍스처 캐시가 사라졌거나 손상된 경우 원본 스킨팩에서 다시 준비합니다. 선택한 스킨팩 자체가 없으면 깨진 BCNG override만 제거합니다.

호환성

- 혼합 설치 환경에서 액터별 CBBE 3BA·UBE 2.0 바디 계열을 감지해 해당 바디 프리셋과 BodySkin만 표시·적용합니다. UBE 2.0 전용 몸·얼굴 경로와 재질 채널을 지원합니다.
- 일반 여성·남성 스킨의 몸·손·발·얼굴, SOS 남성 생식기 텍스처, 아르고니안·카짓 남녀 스킨을 해당 액터의 성별과 종족에 맞춰 처리합니다.
- 스킨팩에 들어 있는 경우에만 노인 몸·손·얼굴 및 인간형 종족별 얼굴 변형을 사용하며, 없는 파일은 기본 텍스처를 유지합니다.
- Racial Skin Variance의 실제 Skin Armor와 FaceGen 소유권을 보존하면서 BCNG BodySkin을 적용하고, RSV의 지연된 얼굴 갱신 뒤 필요한 얼굴 레이어만 한 번 재확인합니다. 바디 프리셋이나 틴트마스크만 사용하는 경우에는 RSV 감시를 추가하지 않습니다.
- Mu Dynamic NormalMap용 normal detail·mask·overlay 동반 파일을 같은 캐시 묶음으로 유지합니다.
- 액터 갱신과 비동기 작업 경계를 정리해 OverlayFix 동시 사용 호환성을 높였습니다.

반응성·성능·안정성

- 바디·스킨·틴트 직접 선택을 자동 NPC 배포보다 우선 처리하면서도, 자동 배포가 굶지 않도록 기존 프레임 처리 예산 안에서 공정하게 분산합니다.
- 선택 액터에게 필요한 스킨 파일만 단일 백그라운드 작업자에서 준비한 뒤 게임 스레드에서 적용합니다. 최신 선택만 유지하고 준비된 캐시는 재사용합니다.
- 같은 DDS가 MO2 실제 모드 경로와 가상 Data 경로에서 함께 발견돼 두 번 전체 해시되던 문제를 수정했습니다. 물리 파일 기준으로 한 번만 검사하며, 대용량 파일별 진단 로그는 디버그 모드로 제한했습니다.
- DDS 전체 내용 검사는 초기 카탈로그 로드와 명시적인 새로고침에서만 실행하고 NPC 이벤트마다 반복하지 않습니다.
- 같은 ID의 XML 또는 DDS 내용이 바뀌면 새로고침에서 감지하며, 변경된 DDS에는 새 캐시 식별자를 사용합니다.
- 완료된 스킨 콜백의 작업 소유권을 즉시 해제하고, 돌아오지 않는 RaceMenu SE 콜백 묶음은 제한 시간 뒤 안전하게 취소합니다. 늦게 도착한 콜백과 오래된 후속 작업은 무효화합니다.
- 스킨과 의상 보정을 사용하지 않는 액터의 장비 이벤트는 BCNG 작업을 만들지 않으며, 규칙·설정·즐겨찾기의 불필요한 전체 복사를 줄였습니다.

검증

- Release 빌드와 회귀 테스트 실행 파일 12종을 모두 통과했습니다.
- 액터 상태 복원, 작업 큐 순서, 콜백 수명·취소, 최신 선택 유지, 바디 계열 분리, 부분 스킨 부위·채널 연결, 카탈로그 새로고침, MO2 경로 별칭 중복 방지를 자동 검증했습니다.
- 기존 배포 조건과 JSON, 설정, 코세이브 식별자, 기본 제외 샘플, 즐겨찾기, 카메라 값은 유지합니다.
