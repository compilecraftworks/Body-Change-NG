Body Change NG v1.2.5 — v1.2.4 대비 변경 사항

- 마우스 입력 좌표를 게임 커서 기준으로 통일했습니다. Windows 버튼 입력은 렌더 단계까지 보관하여 OS 좌표와 Skyrim 커서 좌표가 섞이지 않도록 하고, Scaleform의 중복 마우스 전달을 제외합니다.
- 매 UI 프레임마다 전체 프리셋의 슬라이더 데이터를 복사하지 않고, 새로고침 시 만든 변경 불가 목록 메타데이터를 공유합니다. 화면 밖 바디프리셋 행은 생략하되 키보드 포커스·이동은 유지합니다.
- 액터 복원·3D 갱신 시 이전 세션 내 적용 성공 기록만 신뢰하지 않고 실제 바디 모프 레이어를 재확인합니다. 레이어가 없으면 기존 선택으로 복구하며 배포를 다시 추첨하거나 미리보기를 중단하지 않습니다.
- 일반 NPC 선택 조건은 제보 확인 전까지 변경하지 않았습니다. 입력·복구 변경의 인게임 검증은 아직 남아 있습니다.
