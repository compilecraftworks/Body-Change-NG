# Body Change NG v1.1.2

기능적 강조색을 유지한 블랙·그레이 인터페이스, 검증된 CBBE 3BA 해부학 안전 경계와 수정된 UBE BodySkin 연결 — 2026-09-06.

### 인터페이스 테마

- 푸른빛이 돌던 창·하위 패널·팝업·제목·평상시 버튼·입력칸·카드·표·스크롤바·크기 조절 손잡이·탐색 영역을 검정·차콜·회색 바탕으로 통일했습니다.
- 선택·마우스 오버·눌림 상태의 기존 청색과 경고·성공·진행 상태·즐겨찾기·비호환 표시·실제 틴트 미리보기 색은 기능적 강조색으로 유지합니다.
- 주변 액터 목록 갱신 버튼을 한국어 `액터 새로고침`, 영어 `Refresh actors`, 중국어 `刷新角色`로 줄였습니다. 실제 로드 액터 갱신 동작은 그대로입니다.
- UI 배치·스케일링·키보드/게임패드 입력·카탈로그·카메라·규칙·설정·JSON 스키마·코세이브 식별자·바디/스킨/틴트 적용 경로를 유지합니다.

### 직접 선택과 스킨 갱신

- 기존 프레임 처리 예산 안에서 바디·스킨·틴트 직접 선택을 우선 처리할 기회를 확보하고, 자동 NPC 배포도 계속 처리되도록 했습니다.
- 선택 액터의 필요한 후속 작업에도 우선권을 전달하되, 해당 액터의 미리보기·확정·스킨 적용 순서는 유지합니다.
- 스킨 콜백이 완료되면 작업 소유권을 넘기도록 수정했습니다. VM이 완료된 콜백 객체를 보관한다는 이유만으로 다음 변경이 막히지 않으며, 아직 끝나지 않은 native 호출은 계속 보호합니다.
- RaceMenu SE 콜백 묶음이 돌아오지 않으면 제한 시간 뒤 취소합니다. 늦게 도착한 콜백은 계속 무효이며, 액터 큐는 기존의 한 프레임 안정 경계를 지난 뒤 재개합니다.
- 대기 중 마지막 선택을 유지하고 오래된 스킨 조회의 후속 작업을 생략합니다. 기존 UI 안내 줄에 적용 대기·적용 중·지연 상태를 표시합니다.

### 로드 안전성·미리보기·의상 보정

- 자동 배포·의상 변경·재구성 복원을 같은 태스크 큐 안에서 반복 처리하지 않고 실제 엔진 업데이트 경계에 걸쳐 분산합니다.
- 같은 액터에서 BCNG 갱신이 겹치지 않게 하고, 로드 시 이전 세션 작업을 무효화합니다. 액터 3D가 준비되지 않은 경우의 재시도에도 횟수 제한을 둡니다.
- 다른 NPC의 자동 배포가 선택 액터의 바디 미리보기를 취소하지 않게 했습니다. 세이브를 불러올 때 이전 UI의 미확정 선택을 확정하지 않습니다.
- RaceMenu 종료 후 복원이 진행 중인 액터 작업과 겹치지 않도록 했습니다. 기본 바디·스킨 복원 대기 중 이전 선택값이 다시 선택되는 경로를 수정했습니다.
- 바디 재적용 뒤 의상 보정을 갱신하고, 다른 모드의 모프 키를 삭제하지 않으면서 전체 모프 합성값을 기준으로 절차적 보정을 계산합니다.
- 의상 착용 시 가슴·유두 보정은 확인된 CBBE 3BA 액터에만 적용합니다. UBE는 슬라이더 이름과 0이 아닌 기본값 구성이 크게 다르므로 UBE·불확실 여성 계열에는 추정한 해부학 값이나 가져온/이름 기반 ORefit 레이어를 적용하지 않습니다.
- 유두·생식기 형태 무작위화는 CBBE 3BA NPC 전용입니다. 한국어 UI의 옵션명을 `NPC 유두 형태 무작위화`, `NPC 생식기 형태 무작위화`로 변경하고 영어·중국어에도 같은 의미를 반영했습니다.
- 선택 액터가 UBE이면 안내와 각 옵션 툴팁을 표시합니다. 전역 스위치는 유지하므로 UBE 플레이어는 건너뛰면서 확인된 CBBE 3BA NPC에는 보정·무작위화를 사용할 수 있습니다.
- TAKEALOOK의 UBE 2.0 SliderSet과 OBody NG의 CBBE 중심 ORefit·무작위화 구현을 대조했습니다. 이전 BCNG가 만든 미지원 의상 레이어는 한 번 제거하고 이후 의상 이벤트는 무작업 서명을 재사용합니다.

### 새로고침과 처리 비용

- 같은 프리셋·팩 ID에서도 XML/DDS 내용 변경을 감지합니다. 변경한 DDS를 새로고침하면 이전 텍스처 캐시를 재사용하지 않도록 새 캐시 식별자를 사용합니다.
- 내용 서명과 읽기 전용 규칙 목록을 캐시하고, 전체 카탈로그 반복 복사와 불필요한 강제 보정 의상 인벤토리 탐색을 줄였습니다.
- 자동 바디 배포와 의상 이벤트에서는 즐겨찾기 목록이 포함된 전체 설정을 복사하지 않고 필요한 불리언 옵션만 읽습니다. 스킨과 의상 보정을 모두 사용하지 않는 액터의 장비 이벤트는 작업을 만들지 않습니다.
- 여러 부위가 한 Skin Armor clone에 들어 있는 바디에서도 몸·손·발 geometry를 이름과 실제 텍스처 경로로 분리해 적용합니다. 불완전 스킨팩은 존재하는 부위·채널만 바꾸고, 없는 부위·채널은 현재 원본을 유지합니다.
- 몸·손·발의 영구 상태를 서로 분리된 단일 비트 RaceMenu 스킨 슬롯 키로 저장합니다. 의상에 포함된 정확한 ArmorAddon 피부 노드 갱신도 보조 경로로 유지하여, 일반 Biped 대상이 잡히지 않는 착의·탈의 CBBE 계열/UBE 부위까지 빠지지 않게 했습니다.
- 선택 액터에게 실제 필요한 스킨 텍스처 별칭만 단일 백그라운드 작업자에서 준비한 뒤 geometry 적용을 이어갑니다. 수동 선택은 대량 자동 배포보다 먼저 준비하며, 준비된 캐시는 재사용합니다.
- DDS 전체 읽기는 초기 카탈로그 로드·명시적 새로고침에서만 수행하며 NPC 이벤트마다 반복하지 않습니다. 비용이 큰 적용 후 텍스처 검사는 디버그 모드로 제한합니다.
- Racial Skin Variance 호환 처리를 추가했습니다. BCNG는 액터의 실제 RSV Skin Armor를 대상으로 하고, RSV의 저장된 FaceGen 소유권은 유지한 채 선택한 BCNG 얼굴을 즉시 표시하며, RSV의 지연 노드 갱신 뒤 얼굴만 한 번 합쳐서 재확인합니다. 바디프리셋·틴트마스크만 사용하는 경우에는 RSV 감시나 파일 탐색을 추가하지 않습니다.
- 액터 갱신과 비동기 작업 경계를 정리해 OverlayFix 동시 사용 호환성을 높였습니다.
- MO2가 같은 DDS를 실제 모드 경로와 가상 Data 경로로 노출할 때 발생하던 전체 해시 중복을 제거했습니다. 대용량 스킨팩의 파일별 카탈로그 진단은 디버그 로그로 제한합니다.
- 기존 배포 조건·설정·코세이브 식별자·기본 제외 샘플·바디 계열 필터·스킨 부위/채널 연결·카메라 값은 유지합니다.

### 카탈로그와 배포 안내

- UBE 의상이 보이는 몸 피부를 슬롯 32와 슬롯 53 지오메트리에 나누어 가진 경우 둘을 함께 갱신합니다. UBE Body 아틀라스는 UBE 구조에 맞게 몸·손·발에 일관되게 적용하고 같은 경로로 검증·자동 복구합니다.
- RaceMenu의 저장 키가 제거된 뒤에도 로드된 몸·손·발 클론에 BCNG 텍스처가 남는 경우를 기본 스킨 복원에서 확인합니다. 불일치가 확인된 해당 액터만 한 번 재구성하며 상시 검사나 전체 NPC 순회는 추가하지 않습니다.
- 명시적으로 기본 스킨으로 돌린 액터는 장비 변경 복구 대상으로 계속 기억합니다. 그 액터의 장비가 실제로 바뀔 때만 확인하므로 구버전 의상별 BCNG 키를 제거하면서도 백그라운드 전체 NPC 검사는 추가하지 않습니다.
- 메인 바디스킨 목록은 선택 액터의 실제 바디 계열만 표시합니다. NPC 배포 규칙의 스킨·바디 후보는 모드 설정에서 지정한 여성·남성 NPC 바디 타입만 표시하고 실제 배포에도 같은 필터를 사용합니다.
- 규칙별 바디 계열 드롭다운을 제거하고 현재 모드 설정 계열을 글자로 표시합니다. 전투 스타일은 새 규칙 선택지에서 제외했으며 종족·팩션·플러그인·키워드·클래스 상세 드롭다운은 필드 아래쪽으로만 열립니다. 기존 JSON의 전투 스타일 값은 스키마 호환을 위해 읽을 수 있습니다.
- 메인 탭 이름을 `바디프리셋`, `바디스킨`, `틴트마스크`로 통일하고 플레이어의 틴트마스크 탭을 유지해 목록·설치 안내를 항상 확인할 수 있게 했습니다.
- 바디프리셋·일반/UBE 바디스킨·틴트마스크의 정확한 배치 경로와 새로고침 방법을 빈 목록에 한국어·영어·중국어로 표시합니다.
- 틴트마스크 방식만 호환되며 오버레이 방식은 호환되지 않는다고 명시했습니다.
- 동봉 기본 규칙 8개와 런타임 생성 기본 이름을 영어로 변경했습니다. 사용자가 작성한 기존 규칙 이름은 유지합니다.

### 검증 범위

Release 빌드와 회귀 테스트 실행 파일 12종을 모두 통과했습니다. 큐 순서·콜백 수명/취소·최신 선택·카탈로그 새로고침·MO2 경로 별칭 중복 방지와 기존 연결/상태 규칙을 자동 검증했습니다.

## 1.1.1에서 업데이트

- Skyrim을 종료한 뒤 DLL을 교체합니다.
- 기존 `Data\SKSE\Plugins\BodyChangeNGdistribution.json`, 설정, BodySkin·TintMask·SliderPresets 개인 파일을 유지합니다. MO2 Overwrite·프로필의 활성 사본도 백업하고, 동봉한 기본 JSON으로 개인 배포 규칙을 덮어쓰지 마세요.
- 이번 업데이트 때문에 새 세이브를 만들 필요는 없습니다. JSON 스키마와 코세이브 식별자는 그대로이며, 내용 서명 변경으로 이전 완료 결과가 한 번 재평가·재적용될 수 있습니다.
- 비공개·테스트 빌드가 UBE에 실험적 해부학 값을 기록한 적이 있다면 설치 후 현재 바디 프리셋을 한 번 다시 적용하세요. BCNG는 자기 소유의 확정 모프 키만 재구성하며 다른 모드의 모프 키를 전역 삭제하지 않습니다.
- DDS 전체 내용 검사는 초기 카탈로그 로드 또는 명시적 새로고침 때 수행합니다. 대형 팩은 이 스캔에 시간이 걸릴 수 있으나 NPC마다 반복하지 않습니다.
- 지연 표시는 실패 판정이 아닙니다. 아직 완료되지 않은 native 호출 위에 새 갱신을 강제로 겹쳐 실행하지 않습니다.
