Body Change NG v1.3.4

모프 계산·UBE 의상 보정·스킨 식별·NPC 배포 개선

바디프리셋과 의상 보정

  • 기본 프리셋 수치를 OBody NG 4.4.3과 맞췄습니다. XML의 small/big 끝점을 액터 체중으로 보간한 뒤 100으로 나누며, 생략 끝점은 0으로 읽고 음수·100 초과 값도 유지합니다. 원본 UNP 역방향 슬라이더와 중복 끝점의 첫 비영 값 처리도 반영했습니다. UBE 빌드 기본값 추가 차감과 체중값 제한은 제거했습니다.
  • CBBE 3BA/BHUNP 가슴·유두 보정 및 지원 NPC의 신체 무작위화 수치를 원본 계산과 맞췄습니다. 다른 모프 보존 옵션, 기존 액터 적용 대상, NPC 전용 무작위화, SFS 연동과 취소 가능한 미리보기는 유지합니다.
  • UBE/Necoco에는 Fit to Thicc v1의 Nude → Pushup 차이를 사용하는 별도 가산 보정을 추가했습니다. 가슴 8개와 유두 보정 ON 시 유두·UV 6개를 체중에 맞춰 더하며 BCNG·RaceMenu 모프를 차감하지 않습니다. 기준 자료의 NipplesShowUp 기본값은 이 고정 보정표에만 사용하며 일반 프리셋 XML 읽기에는 영향을 주지 않습니다.
  • 플레이어가 UBE여도 전역 의상·유두 보정 옵션을 조절할 수 있습니다. 유두 보정 OFF는 해당 보정만, 의상 보정 OFF나 탈의는 전체 의상 보정 레이어를 제거합니다. 각 액터의 실제 바디 계열에 맞는 계산을 사용합니다.
  • ORefit 이름·플러그인·FormID 제외를 지원 계열의 가슴·유두 보정 모두에 적용합니다. 명시적 강제 보정과 호환 Refit 프리셋의 기존 우선순위를 유지합니다. SFS 사용 시 최종 표시 의상, 그 외에는 실제 장비를 기준으로 판단합니다. 기존 저장 프리셋과 보정 레이어는 기존 작업 큐에서 한 번 재평가합니다.

스킨·오버레이·틴트마스크

  • 스킨·후타스킨·오버레이·틴트의 에셋 ID, DDS 경로·확장자는 영문 대소문자를 구분하지 않고 경로 구분자도 동일하게 처리합니다. 기존 저장 문자열과 세이브 형식은 유지하며 즐겨찾기·미리보기 색상·복원에도 같은 식별 기준을 적용했습니다.
  • 게임이 대소문자만 다른 기존 파일명 문자열을 재사용할 때 정상 스킨 기록을 실패로 오인하던 문제를 수정했습니다. ID 표기 차이만으로 스킨을 반복 재생성하지 않으며 텍스처 소유권·슬롯 예약·경로 안전성 검사는 유지합니다.
  • SlaveTats / SlaveTats NG가 슬롯 해제 후 남긴 정확한 빈 DDS를 인식하여 얼굴·몸·손·발 슬롯을 0/0 등으로 오인하던 문제를 수정했습니다. 투명 문신을 포함한 등록 텍스처·색상·투명도는 1·3인칭 모두 보호하며 다른 빈 텍스처나 다른 모드의 문신 기록은 건드리지 않습니다.

NPC 배포

  • 모든 배포 지원 탭에서 체크박스 선택·조건 편집 중에는 액터 드롭다운·새로고침 대신 “선택된 항목을 범위 지정하여 월드 NPC에게 배포”를 표시합니다. 한·영·중 타이틀을 한 줄로 맞추며 배포 모드를 끝내면 액터 선택 UI가 돌아옵니다.
  • 설정한 UBE 프리셋과 UBE Zeroed가 배포 체크박스 목록·실제 배포 후보에서 누락되던 문제를 수정했습니다. 일반 목록은 선택 액터 기준, 배포 후보는 설정 기준이며 미리보기는 현재 액터와의 호환성을 유지합니다.
  • 자동 프리셋 선택을 기록하기 전에 설정 계열과 받는 NPC의 확인된 계열을 모두 검사하고, 후보별 슬라이더 전체 복사를 피합니다. 성별 검사·계열 미확인 처리·오버레이 누적 미리보기·색상은 유지합니다. NPC 몸을 다른 계열로 바꾸거나 스킨·후타의 기존 배포 제한을 확장하는 변경은 아닙니다.

업데이트와 검증

  • 사용자 BodyChangeNGdistribution.json, 설정, 팩과 텍스처 캐시를 보존하세요. 규칙은 schema 8을 유지하고 시작 파일의 활성 규칙은 0개입니다. 새 런타임 훅·반복 검사·영구 캐시·의존성·RaceMenu ABI·코세이브 형식 변경은 없습니다.
  • Release 빌드와 오프라인 회귀 실행 파일 38개를 통과했습니다. 원본 모프 수치 대조, 배포 후보, 1,000회 목록 전환, 타이틀 배치 36개 조합과 대소문자 혼합 경로·식별 검사를 포함합니다. 앞서 시행한 오버레이 판정 120만 회 할당 검사에서는 잔존 블록·바이트가 0이었습니다.
  • 사용자가 두부팩에서 최신 빌드의 인게임 정상 동작을 확인했습니다. 모든 지원 런타임·환경의 검증이나 엔진 전체 누수 보장을 뜻하지 않습니다. 마우스·입력 구현은 변경하지 않았습니다.
