Body Change NG v1.3.4

오버레이 슬롯·UBE 프리셋 배포 수정과 배포 타이틀 개선

NPC 배포

  • 배포를 지원하는 모든 탭에서 액터 드롭다운·액터 새로고침 대신 “선택된 항목을 범위 지정하여 월드 NPC에게 배포”를 표시합니다. 한·영·중 타이틀이 폭에 맞게 한 줄로 표시됩니다. 의상·랜덤화와 모드 설정은 유지하며 배포 모드를 끝내면 액터 선택 UI가 돌아옵니다.
  • 설정에서 UBE를 선택해도 UBE 프리셋이 배포 목록과 실제 배포 후보에서 빠지던 문제를 수정했습니다. UBE Zeroed도 포함합니다. 일반 목록은 선택 액터 기준, 배포 후보는 설정 계열 기준이며 미리보기는 액터 호환성을 확인합니다.
  • 자동 프리셋 선택을 기록하기 전에 설정 계열과 받는 NPC의 확인된 계열을 모두 검사합니다. 성별 검사와 계열 미확인 시 기존 처리를 유지하고, 후보마다 슬라이더 전체를 복사하지 않고 목록 정보를 읽습니다.
  • NPC의 몸을 다른 계열로 바꾸거나 계열별 동시 배포 설정을 추가하는 변경은 아닙니다. 스킨·후타의 기존 자동 배포 제한은 유지합니다.

오버레이 슬롯

  • SlaveTats / SlaveTats NG가 등록 정보를 지운 뒤 노드에 남길 수 있는 정확한 빈 텍스처를 인식합니다. 해제된 얼굴·몸·손·발 슬롯을 점유 상태로 오인하여 0/0 등으로 표시하거나 재사용하지 못하던 문제를 수정했습니다.
  • 등록된 텍스처·색상·투명도 설정은 계속 보호하며 투명한 문신도 빈 슬롯으로 취급하지 않습니다. 로드된 1인칭·3인칭을 모두 확인하고 다른 폴더의 blank.dds와 다른 모드의 문신 기록은 건드리지 않습니다.
  • 기존 소유권 검사, 체크박스 누적 미리보기, 색상 편집, 지연 적용과 세이브 복원을 유지합니다. 새 캐시·반복 검사·의존성·런타임 레이아웃·RaceMenu 인터페이스·저장 형식 변경은 없습니다.

업데이트

직접 편집한 BodyChangeNGdistribution.json은 보존하세요. schema 8을 유지하며 배포 템플릿의 활성 규칙은 0개입니다.

검증

  • Release 빌드와 오프라인 회귀 실행 파일 37개를 통과했습니다. 실제 목록·배포 후보 함수, 1,000회 목록 모드 전환, 타이틀 배치 36개 조합을 포함합니다.
  • 변경된 오버레이 슬롯 판정을 120만 회 호출한 할당 검사에서 잔존 블록·바이트가 모두 0이었습니다. 엔진 전체의 누수 보장을 뜻하지는 않습니다. 이번 릴리즈의 인게임 테스트는 수행하지 않았습니다.
