Body Change NG 1.2.0

- 일반 BodySkin 재도색을 NPC ActorBase에 연결하는 전용 네이티브 TXST -> ArmorAddon -> Skin Armor 그래프로 교체했습니다.
- 기본 바디스킨을 장비 추적에서 분리했습니다. Skyrim이 선택된 네이티브 스킨 원본에서 알몸 몸·손·발·얼굴을 다시 생성합니다.
- 스킨 카탈로그 분류와 런타임 BodyFamily를 분리했습니다. 명시적 !UBE 구조만 UBE이고 나머지 일반 인간형 스킨팩은 Legacy입니다.
- 스킨팩 profile.json 지원을 제거했습니다. 기존 자동 ID는 상대 폴더와 감지 성별을 그대로 사용합니다.
- 부분팩과 몸·손·발·얼굴 정확 라우팅을 유지합니다. 없는 DDS 부위·채널은 현재 공급자 값을 유지합니다.
- CBBE 3BA와 BHUNP/UNP의 질·항문 아틀라스를 일치하는 실제 지오메트리에만 연결합니다.
- 남성 SOS/TNG와 여성 SOS/TNG/TRX/ERF 성기 스킨을 서로 독립된 액터 레퍼런스 어댑터로 유지합니다.
- RSV 공급자 재기반과 제한된 얼굴 복구를 추가하고 RSV 저장 키 소유권은 가져오지 않습니다.
- 바디·스킨·틴트·후타나리·RSV 얼굴·의상 작업을 분리하여 한 기능이 다른 기능을 취소하거나 초기화하지 않게 했습니다.
- NPC 바디/스킨 배포 저장, 기본값과 변경 없음 구분, ActorBase 스킨 소유권, 세이브 로드 시 전용 폼 재사용을 수정했습니다.
- 같은 프리셋 이름이 여러 BodyFamily나 XML 소스에 있을 때 OBody NG 배포 가져오기가 한 ID만 남기던 문제를 수정했습니다. 일치하는 모든 영구 ID를 보존하고 런타임에서 액터 계열에 맞게 거릅니다.
- OBody NG ORefit의 의상 이름·플러그인·FormID 제외를 실제 런타임 판정 경로로 검증했습니다. 등록 시 현재 로드된 모든 액터의 BCNG 의상 보정을 즉시 다시 판정합니다.
- 기본 샘플 규칙을 수정·순서 변경·삭제할 수 있고 새 규칙 ID 충돌을 막습니다. 가려진 규칙을 경고하고 자동 이름을 한국어·영어·중국어로 표시합니다.
- 설정·배포 규칙을 검증된 임시 파일과 원자 교체로 저장합니다.
- 검증된 Skyrim SE 1.5.97과 AE 1.6.x(1.6.1179까지)를 지원합니다. Skyrim VR은 지원하지 않습니다.
- Release 빌드와 자동 회귀 테스트 15종을 모두 통과했으며, 실제 떼껄룩·툴레드 OBody JSON도 함께 점검했습니다.

중요: 1.2.0은 1.1.4와 별도 아키텍처입니다. 두 버전 DLL을 섞지 마세요. 기존 모드를 교체하기 전에 BodyChangeNGdistribution.json과 개인 에셋 폴더를 보존하세요. 설정·배포 규칙 JSON은 계속 지원하며 스킨팩별 profile.json 형식만 제거됐습니다.
