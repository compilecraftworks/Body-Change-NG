Required skin-pack layout:

BodySkin\<skin name>\Textures\

Copy a skin mod's existing textures folder contents directly here. For example:

BodySkin\Zhizhen's Skins\Textures\actors\character\female\femalebody_1.dds

Beast-race packs use the same BodySkin root and preserve their original paths:
BodySkin\<skin name>\Textures\actors\character\argonianfemale\...
BodySkin\<skin name>\Textures\actors\character\argonianmale\...
BodySkin\<skin name>\Textures\actors\character\khajiitfemale\...
BodySkin\<skin name>\Textures\actors\character\khajiitmale\...

Every skin stays self-contained under its own BodySkin folder. Body Change NG
shows separate compatible rows per detected race and sex, and filters them by
the selected actor's race, sex, and runtime body family. Folder names do not
select a UV layout. Only an explicit Textures\!UBE\Body or Head tree is UBE;
every other conventional humanoid texture tree is Legacy. Skin-pack metadata
JSON is not read.

Partial packs are valid. Only supplied body, hands, feet, and face channels are
overridden; missing parts/channels retain the actor's current textures. Only a
verified humanoid layout may use its body atlas for feet when no separate feet
atlas exists. Beast-race and unknown layouts never borrow it; hands always stay
independent except for UBE's explicitly shared Body atlas.
