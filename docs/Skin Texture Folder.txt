Required skin-pack layout:

BodySkin\<skin name>\Textures\

Copy a skin mod's existing textures folder contents directly here. For example:

BodySkin\Zhizhen's Skins\Textures\actors\character\female\femalebody_1.dds

Every skin stays self-contained under its own BodySkin folder. Body Change NG
shows one row per top-level skin folder and filters rows by the selected
actor's sex. If you add a profile.json, use a relative path such as
Textures\actors\character\female\femalebody_1.dds.

Partial packs are valid. Only supplied body, hands, feet, and face channels are
overridden; missing parts/channels retain the actor's current textures. A body
texture is never reused for the hands or feet, and vice versa.
