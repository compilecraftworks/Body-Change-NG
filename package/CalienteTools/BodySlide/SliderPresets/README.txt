Body Change NG - BodySlide 프리셋 설치 안내

BodySlide 프리셋 XML 파일을 이 폴더에 넣으세요.

경로:
CalienteTools\BodySlide\SliderPresets\*.xml

기존 BodySlide 프리셋 모드와 같은 XML 파일을 사용합니다. 게임 실행 중
XML을 추가했다면 Body Change NG의 바디 탭에서 새로고침을 누르세요.
메인 바디 탭은 선택한 액터의 성별과 감지된 바디 계열에 맞춰 표시하며,
판정이 불확실한 프리셋은 안전한 폴백 목록에 남깁니다.

English:
Place standard BodySlide SliderPresets XML files in this folder. Press Refresh
on the Body tab after adding files while the game is running.
