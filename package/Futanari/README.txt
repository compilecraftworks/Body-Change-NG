Body Change NG - 후타나리 스킨팩 설치 안내

이 폴더 아래에 후타나리 스킨팩마다 별도의 폴더를 만드세요.
선택한 액터에게 현재 장착된 성기 메시와 바디 계열에 맞는 경로만
후타나리 탭에 표시됩니다.

지원 구조:

1. UBE + UBE SOS/TNG 성기
Futanari\<스킨팩 이름>\Textures\!UBE\Body\malebody_1_d.dds
Futanari\<스킨팩 이름>\Textures\!UBE\Body\malebody_1_n.dds
Futanari\<스킨팩 이름>\Textures\!UBE\Body\femalebody_1_sk.dds

2. CBBE 3BA + TRX Futa Addon
Futanari\<스킨팩 이름>\Textures\[TRX] Futa addon\Regular\Default\schlong.dds
Futanari\<스킨팩 이름>\Textures\[TRX] Futa addon\Regular\Default\schlong_msn.dds
Futanari\<스킨팩 이름>\Textures\[TRX] Futa addon\Regular\Default\schlong_s.dds
Futanari\<스킨팩 이름>\Textures\[TRX] Futa addon\Regular\Default\schlong_sk.dds

같은 Default 폴더에 wetschlong_110_s.dds 같은 wet schlong specular가
있으면 선택한 스킨의 런타임 캐시에 함께 포함됩니다. wet 파일은
schlong_s.dds를 대신하지 않으며, 해당 wet 효과가 참조할 수 있도록
같은 캐시 폴더에 원래 파일명으로 유지됩니다.

3. CBBE 3BA + ERF Futanari
Futanari\<스킨팩 이름>\Textures\ERF_Futanari\FairSkinCBBE\futanari_schlong.dds
Futanari\<스킨팩 이름>\Textures\ERF_Futanari\FairSkinCBBE\futanari_schlong_msn.dds
Futanari\<스킨팩 이름>\Textures\ERF_Futanari\FairSkinCBBE\futanari_schlong_s.dds
Futanari\<스킨팩 이름>\Textures\ERF_Futanari\FairSkinCBBE\futanari_schlong_sk.dds

없는 텍스처 채널은 다른 부위나 다른 채널로 복제하지 않습니다.
게임 실행 중 스킨팩을 추가했다면 후타나리 탭에서 새로고침을 누르세요.
기본 후타나리 스킨을 선택하면 Body Change NG가 만든 성기 텍스처
오버라이드만 제거하고 설치된 성기 모드의 원래 스킨으로 돌아갑니다.

후타나리 상태를 해제해 성기 메시가 사라져도 선택값은 저장됩니다.
같은 액터가 다시 후타나리 상태가 되면 저장된 스킨을 자동으로 다시
적용합니다.

English:
Create one folder per futanari skin pack and keep the original texture names
under one of the supported paths below:

UBE with the UBE SOS/TNG genital mesh:
Futanari\<pack name>\Textures\!UBE\Body

CBBE 3BA with TRX Futa Addon:
Futanari\<pack name>\Textures\[TRX] Futa addon\Regular\Default

CBBE 3BA with ERF Futanari:
Futanari\<pack name>\Textures\ERF_Futanari\FairSkinCBBE

Wet companions such as wetschlong_110_s.dds are kept beside the selected TRX
schlong_s.dds in the private runtime cache. Missing channels are never copied
from another body part or texture channel. Press Refresh on the Futanari tab
after adding a pack while the game is running.
