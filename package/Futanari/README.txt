Body Change NG v1.2.0 — Futanari 설치 안내

[한국어]
설치된 후타스킨 모드 폴더를 통째로 이 Futanari 폴더 안에 복사하세요.
기존 Textures 디렉터리와 애드온별 하위 구조를 그대로 유지합니다.
FOMOD는 모드 매니저에서 옵션을 고른 설치 결과 폴더를 사용하세요.

게임 Data 기준 전체 DDS 경로 예시:
Data\Futanari\My UBE Addon Skin\Textures\!UBE\Body\malebody_1_d.dds
Data\Futanari\My TRX Skin\Textures\[TRX] Futa addon\Regular\Default\schlong.dds
Data\Futanari\My ERF Skin\Textures\ERF_Futanari\FairSkinCBBE\futanari_schlong.dds

MO2 설치 폴더 기준 복사 예시:
원본: mods\My ERF Skin\Textures\ERF_Futanari\FairSkinCBBE\futanari_schlong.dds
복사: mods\Body Change NG\Futanari\My ERF Skin\Textures\ERF_Futanari\FairSkinCBBE\futanari_schlong.dds

MO2 모드 최상위는 게임 Data에 해당하므로 모드 안에 Data를 또 만들지 마세요.
별도 에셋 모드 최상위에 Futanari를 두어도 됩니다.

- UBE의 _d/_n/_sk, TRX/ERF의 diffuse/_msn/_sk/_s와 제공되는 wet 맵을 보존합니다.
- 애드온 유형과 실제 메시 UV에 맞는 스킨을 사용합니다. 이름 변경은 UV 변환이 아닙니다.
- 지원 여성 SOS/TNG 애드온이 설치·로드되어 있어야 후타스킨 탭이 활성화됩니다.
- 일반 남성 애드온만 설치한 경우에는 후타 기능을 활성화하지 않습니다.
- 수동 변경은 SOS/TNG에 지원 후타 애드온으로 등록된 여성 액터만 가능합니다.
- 등록된 액터가 아직 없어도 지원 여성 애드온을 설치했다면 탭과 배포 도구는 활성화됩니다.
- 스킨 선택은 애드온 설치·후타 등록·장착을 대신하지 않습니다.
- 애드온 본체와 선행 모드는 원래 방식으로 정상 설치하세요.
- 일반 남성 SOS/TNG 스킨은 Futanari가 아니라 BodySkin 남성 팩에 넣습니다.

스킨을 한 번 클릭하면 미리보기, 더블클릭하면 확정합니다.
확정하지 않고 창을 닫으면 원래 선택을 유지합니다.
일부 지원 런타임은 성기 TXST 경로의 추가 검증이 필요합니다.
정확한 버전별 범위는 v1.2.0 소개글의 호환 안내를 확인하세요.

[English]
Copy the whole installed futanari-skin mod folder into Futanari and preserve
its original Textures tree. The complete DDS and MO2 copy examples are above.
Use the installed FOMOD result rather than an unresolved installer archive.
In MO2, the mod root is Data; a second Data folder is not needed.

Keep the addon's companion maps and optional wet textures. Match the actual
addon/mesh UV layout; renaming a DDS does not convert ERF, TRX, and UBE skins.
Supported female SOS/TNG addon installation/loading enables the feature, even
when no eligible actor is present. Ordinary male addons do not enable it.
Manual editing additionally requires a female actor registered with a supported
futanari addon in SOS/TNG. Skin selection does not install/equip/register an addon.
Install the addon and its requirements normally. Male addon skins belong in BodySkin.

Single-click previews; double-click confirms; close without confirmation to
restore the previous selection. See the v1.2.0 description for runtime-specific
native genital-backend verification limits.
